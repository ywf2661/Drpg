# 4단계 보스 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 5층 가장 먼 방에 미노타우르스를 두고, 처치하면 클리어.

**Architecture:** 생성기가 5층에 `M`을 놓고, sim이 `boss` 종류와 클리어 판정을 처리한다. 변환 스크립트가 다중 이미지 FLARE 정의를 읽어 boss 시트를 만들고, HUD가 보스 체력바를 그린다.

**Tech Stack:** TypeScript, three.js, Vitest, Python + Pillow.

**Spec:** `docs/superpowers/specs/2026-10-15-boss-design.md`

## Global Constraints

- 보스 체력 300, 데미지 10–16, 간격 1.6초, 속도 2.4, 드롭 0 (모두 층 배율 적용 규칙은 기존과 같음).
- 맵 글자 `M`. sim에 three.js·Math.random 금지.

## Review Focus

1. 보스가 죽었는데 다른 몬스터가 남아 있음 → clear (Task 2 테스트).
2. 5층에서 보스 칸 근처에 소품이 막아 보스가 갇힘 → 보스 주변 3칸 비움 (Task 1 테스트).
3. 층 이동·재시작 후 보스 체력바가 이전 층 보스를 가리킴 → 매 프레임 현재 world에서 찾음 (Task 3 헤드리스).
4. 보스 시트가 4096px 초과 → 스크립트 assert, 배율 조정 (Task 3).
5. 보스 공격 애니메이션 프레임 = 1.6초 간격에 맞춤 → `attackInterval` 공용 (Task 2·3).

### Task 2: sim — 보스 종류와 클리어

**Files:** `src/sim/world.ts`, `src/sim/world.test.ts`

- [ ] 테스트:

```ts
test('M은 보스: 체력·데미지에 층 배율', () => {
  const w = createWorld(1, ['H...M'], 1.8);
  const b = w.entities[1];
  expect(b.kind).toBe('boss');
  expect(b.maxHp).toBe(540);
});

test('보스가 있는 층은 보스가 죽으면 클리어(다른 몬스터 생존 무관)', () => {
  const w = createWorld(1, ['H.m..M']);
  expect(outcome(w)).toBeNull();
  w.entities.find((e) => e.kind === 'minion')!.state = 'dead';
  expect(outcome(w)).toBeNull();
  w.entities.find((e) => e.kind === 'boss')!.state = 'dead';
  w.entities.find((e) => e.kind === 'minion')!.state = 'idle';
  expect(outcome(w)).toBe('clear');
});

test('보스는 아무것도 떨어뜨리지 않는다', () => {
  for (let seed = 1; seed <= 100; seed++) {
    const w = createWorld(seed, ['HM']);
    w.entities[1].hp = 1;
    run(w, 60, [{ type: 'attack', targetId: 1 }]);
    expect(w.entities[1].state).toBe('dead');
    expect(w.items).toEqual([]);
  }
});
```

- [ ] 구현: `Kind`에 `'boss'`, `STATS.boss = { name: '미노타우르스', hp: 300, dmg: [10, 16], interval: 1.6, speed: 2.4 }`, `SPAWN.M = 'boss'`, `POTION.drop.boss = 0`, `GEAR_DROP.boss = 0`. `outcome`: 계단 분기 뒤 `const boss = w.entities.find((e) => e.kind === 'boss'); if (boss) return boss.state === 'dead' ? 'clear' : null;`.
- [ ] `npm test` → 커밋 `feat: 보스 종류와 보스 처치 클리어`.
