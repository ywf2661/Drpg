# 3-A단계 체력 물약 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 몬스터가 물약을 떨어뜨리고, 자동으로 주워 Q/버튼으로 마시며, 층을 내려가도 물약이 유지된다.

**Architecture:** sim(`world.ts`)에 `items`·`potions`·`drink` 명령을 추가하고, main이 층 사이 물약 수를 관리한다. 렌더는 `props.ts`의 판자로 바닥 물약을, HTML 버튼으로 허리띠를 그린다.

**Tech Stack:** TypeScript, three.js, Vitest, Python + Pillow.

**Spec:** `docs/superpowers/specs/2026-10-15-potions-design.md`

## Global Constraints

- sim은 three.js·Math.random 금지, 난수는 `rand(w)`만.
- 드롭 졸개 0.2, 전사 0.35 / 줍기 반경 0.6m / 허리띠 8 / 회복 최대 체력의 50% / 시작 2개.

## Review Focus

1. 시체 위에 떨어진 물약을 주인공이 시체를 공격하던 자리에서 바로 줍는가 → 0.6m 반경이면 근접 사거리(1.5m)보다 작으므로 걸어가야 함. 공격 후 자동 이동은 없음(허용, 디아블로도 직접 걸어감).
2. 같은 틱에 두 몬스터가 죽어 물약 2개 → id가 겹치지 않음 (Task 2 테스트: id 고유).
3. 체력이 가득할 때 Q 연타로 물약 낭비 → 마시지 않음 (Task 2 테스트).
4. 사망 직후 Q → 마시지 않음 (Task 2 테스트).
5. 층 이동 직후 이전 층 물약 판자가 남는 경우 → `setWorld`에서 모두 교체 (Task 3 헤드리스).

### Task 2: sim — 드롭·줍기·마시기

**Files:** Modify `src/sim/world.ts`, `src/sim/world.test.ts`.

**Produces:** `World.items: Item[]`, `export type Item = { id: number; x: number; z: number }`, `World.nextItem`, `World.potions`, `Command` += `{ type: 'drink' }`, 상수 `export const POTION = { drop: { minion: 0.2, warrior: 0.35 }, pickup: 0.6, max: 8, heal: 0.5 }`.

- [ ] 테스트 (world.test.ts 끝):

```ts
const kill = (seed: number, kind: 'm' | 'w') => {
  const w = createWorld(seed, ['H' + kind + '.']);
  w.entities[1].hp = 1;
  run(w, 60, [{ type: 'attack', targetId: 1 }]);
  return w;
};

test('몬스터가 죽으면 확률로 물약을 그 자리에 떨어뜨린다(졸개 약 20%, 전사 약 35%)', () => {
  for (const [kind, lo, hi] of [['m', 0.12, 0.28], ['w', 0.25, 0.45]] as const) {
    let drops = 0;
    for (let seed = 1; seed <= 400; seed++) {
      const w = kill(seed, kind);
      expect(w.entities[1].state).toBe('dead');
      if (w.items.length) {
        drops++;
        expect(w.items[0]).toMatchObject({ x: w.entities[1].x, z: w.entities[1].z });
      }
    }
    expect(drops / 400).toBeGreaterThan(lo);
    expect(drops / 400).toBeLessThan(hi);
  }
});

test('물약 드롭은 시드로 재현되고 id는 고유', () => {
  const seeds = Array.from({ length: 50 }, (_, i) => i + 1);
  expect(seeds.map((s) => kill(s, 'm').items.length)).toEqual(seeds.map((s) => kill(s, 'm').items.length));
  const w = createWorld(1, ['H....']);
  w.items.push({ id: w.nextItem++, x: 3.5, z: 0.5 });
  expect(w.nextItem).toBe(1);
});

test('지나가면 물약을 줍고, 허리띠가 가득 차면 바닥에 남긴다', () => {
  const w = createWorld(1, ['H....']);
  w.items.push({ id: w.nextItem++, x: 2.5, z: 0.5 });
  run(w, 70, [{ type: 'move', x: 4.5, z: 0.5 }]);
  expect(w.potions).toBe(1);
  expect(w.items).toEqual([]);
  const full = createWorld(1, ['H....']);
  full.potions = 8;
  full.items.push({ id: full.nextItem++, x: 2.5, z: 0.5 });
  run(full, 70, [{ type: 'move', x: 4.5, z: 0.5 }]);
  expect(full.potions).toBe(8);
  expect(full.items).toHaveLength(1);
});

test('물약을 마시면 최대 체력의 50% 회복(최대치까지), 가득하거나 없거나 죽었으면 마시지 않는다', () => {
  const w = createWorld(1, ['H..']);
  const hero = w.entities[0];
  w.potions = 2;
  hero.hp = 30;
  step(w, [{ type: 'drink' }]);
  expect([hero.hp, w.potions]).toEqual([80, 1]);
  step(w, [{ type: 'drink' }]);
  expect([hero.hp, w.potions]).toEqual([100, 0]);
  w.potions = 1;
  step(w, [{ type: 'drink' }]);
  expect(w.potions).toBe(1);
  hero.hp = 10;
  w.potions = 0;
  step(w, [{ type: 'drink' }]);
  expect(hero.hp).toBe(10);
  w.potions = 1;
  hero.hp = 0;
  hero.state = 'dead';
  step(w, [{ type: 'drink' }]);
  expect(w.potions).toBe(1);
});

test('마시기는 이동과 계단 의도를 끊지 않는다', () => {
  const w = createWorld(1, ['H..>', '....']);
  w.potions = 1;
  w.entities[0].hp = 50;
  step(w, [{ type: 'move', x: 3.5, z: 0.5 }]);
  run(w, 60, [{ type: 'drink' }]);
  expect(outcome(w)).toBe('descend');
});
```

- [ ] 실패 확인 → 구현:
  - `createWorld` 반환에 `items: [], nextItem: 0, potions: 0`.
  - `command()` 맨 앞: `if (c.type === 'drink') return drink(w, hero);` (`toStairs`를 건드리지 않도록 그보다 앞).
  - `drink`: 죽었거나 0개거나 체력 가득이면 무시, 아니면 `hero.hp = Math.min(hero.maxHp, hero.hp + Math.round(hero.maxHp * POTION.heal)); w.potions--`.
  - `damage()`에서 대상이 죽고 주인공이 아니면 `if (rand(w) < POTION.drop[t.kind]) w.items.push({ id: w.nextItem++, x: t.x, z: t.z })`. (주인공 사망 시에는 rand를 소비하지 않음)
  - `step()` 끝(separate 뒤): `pickup(w)` — 주인공이 살아 있으면 0.6m 이내 물약을 허리띠가 찰 때까지 줍는다.
- [ ] 전체 테스트 통과 → 커밋 `feat: 물약 드롭·자동 줍기·마시기`.

### Task 3: 진행·입력·HUD·렌더

**Files:** Modify `src/main.ts`, `index.html`, `src/render/props.ts`, `src/render/render.ts`.
