# 벼림 연출 보강 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 강화된 휘두름이 맞은 적 위에서 보이고, 해방 참격이 발도 칼선만큼 또렷하게.

**Architecture:** sim은 강화 효과를 준 적마다 짧게 사는 기록(`World.edgeHits`)을 남기기만 한다. 화면(`render.ts`)은 새 기록을 한 번 꺼내 데미지 숫자 나누기·번쩍임 색에 쓰고, `temper.ts`에 넘겨 칼 궤적·불티·적 위 터짐·해방 칼선을 그린다. 칼선은 발도(`iaido.ts`)의 `line()`을 가져다 쓴다.

**Tech Stack:** TypeScript, three.js, vitest(`npm test`)

**Spec:** `docs/superpowers/specs/2026-11-18-temper-fx-design.md`

## Global Constraints

- 수치·판정·충전 규칙은 그대로(sim은 기록 추가만).
- 새 그림 시트·새 소리 없음.
- `edgeHits`는 저장하지 않는다(`combos`처럼).
- 주석·문구는 자연스러운 한국어.

## Review Focus

- 회오리 + 불 벼림: 0.25초마다 휘두름 — 적 위 터짐은 적마다 0.15초에 한 번, 소리는 프레임에 하나. 화면이 번쩍임으로 덮이지 않아야 한다(Task 4 눈 확인).
- 해방 중 회오리: 멈칫이 휘두름마다 붙어도 끈적이지 않아야 한다(멈춤 0.03초, 맞힌 적이 있을 때만).
- 적이 죽는 타격: 추가 피해가 남은 체력보다 클 때 숫자 합이 실제 잃은 체력을 넘지 않는다(Task 3 `splitLost` 테스트).
- 층 이동: 새 층에서 옛 기록 id로 터짐이 나오면 안 된다(`resetTemper`가 본 id를 맞춘다, Task 4).
- 낮 바깥 지역에서도 불티·터짐이 보인다(가산 혼합, Task 4 눈 확인).

- [ ] **Step 1: 실패하는 테스트** (`temper.test.ts`, 기존 `arena`·`flame()` 사용)

```ts
test('강화 기록: 효과를 준 적마다 하나, 못 맞히면 없음', () => {
  const w = arena(['H.s..'], { cleave: 1, flameEdge: 1 });
  w.edge = flame();
  const foe = w.entities[1];
  const before = foe.hp;
  temper(w, w.entities[0], [foe]);
  expect(w.edgeHits).toHaveLength(1);
  expect(w.edgeHits[0]).toMatchObject({ ent: foe.id, kind: 'flame', freeze: false, dmg: before - foe.hp });
  expect(w.edgeHits[0].dmg).toBeGreaterThan(0);
  temper(w, w.entities[0], []);
  expect(w.edgeHits).toHaveLength(1);
});
test('강화 기록: 서리는 피해 0, 언 타수에 freeze', () => {
  const w = arena(['H.s..'], { cleave: 1, frostEdge: 1 });
  w.edge = { kind: 'frost', left: 6, t: 0 };
  const foe = w.entities[1];
  for (let i = 0; i < 3; i++) temper(w, w.entities[0], [foe]);
  expect(w.edgeHits.map((h) => [h.dmg, h.freeze])).toEqual([[0, false], [0, false], [0, true]]);
});
test('강화 기록은 hitAge 뒤 사라진다', () => {
  const w = arena(['H.s..'], { cleave: 1, flameEdge: 1 });
  w.edge = flame();
  temper(w, w.entities[0], [w.entities[1]]);
  runFor(w, 0.6);
  expect(w.edgeHits).toHaveLength(0);
});
```
(맵 글자 `s`가 적이 아니면 기존 테스트에서 쓰는 적 글자로 바꾼다.)

- [ ] **Step 2: 실패 확인** — `npm test -- src/sim/temper.test.ts` → `edgeHits` undefined로 FAIL
- [ ] **Step 3: 구현** — `temper()`의 적 루프에서 `hp` 전후 차로 `dmg`, 이번에 `stun`했으면 `freeze: true`, `id: w.nextItem++`로 push. `world.ts` 틱에 `w.edgeHits = w.edgeHits.filter((h) => (h.age += DT) <= TEMPER.hitAge)`.
- [ ] **Step 4: 통과 확인** — `npm test` 전체 PASS
