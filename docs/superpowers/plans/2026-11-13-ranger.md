# 궁수 직업 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 세 번째 직업 궁수(`ranger`) — 화살 평타, 명사수 패시브, 관통 사격·덫·화살비·집중, 기사 구르기.

**Architecture:** 마법사와 같은 경로. 수치는 `src/sim/rules.ts`, 스킬 로직은 새 `src/sim/ranger.ts`, `world.ts`의 `command`/`step`/`swing`과 `abilities.ts`의 `fly`에서 직업별로 부른다. 그림은 `tools/sprites.py`가 만든 `ranger_<레이어>_<단계>.png`(hero.json 공유).

**Tech Stack:** TypeScript, three.js, vitest, Python 3 + Pillow(그림 도구).

**Spec:** `docs/superpowers/specs/2026-11-13-ranger-design.md`

## Global Constraints

- 직업 id `ranger`, 화면 이름 `궁수`. `Kind`의 `'archer'`(스켈레톤 궁수)는 건드리지 않는다.
- 체력 85, 레벨당 8. 평타 사거리 7.5m. 명사수: 5m 넘게 떨어진 적에게 주는 피해 ×1.25.
- 스킬 칸 매핑: Q `skill`/`cleave` = 관통 사격, W `dash` = 덫, E `shout` = 화살비, R `throw` = 집중, 스페이스 `roll` = 기사 구르기(`rollStart`).
- 새 상태 이상·탄약·여자 외형·직업 일반화 리팩터링은 하지 않는다.
- 주석·UI 문구는 한국어, 기존 파일의 짧은 한 줄 주석 스타일.
- 테스트: `npx vitest run <파일>`. 전체: `npm test`, 타입: `npx tsc --noEmit`.

## Review Focus

1. 덫·화살비 대기열(`traps`, `volleys`)이 층을 내려가면 비워지는가 — 새 층에 지난 층 덫이 남으면 안 된다(Task 3, 4 테스트).
2. 관통 사격이 벽 바로 앞에서 쏴도 터지지 않고 사슬 문을 연다(Task 2 테스트).
3. 저장 → 불러오기에서 `cls: 'ranger'`가 유지되고, 모르는 직업은 여전히 거부된다(Task 1 테스트).
4. 구르는 중(무적)이나 죽은 뒤에 덫·화살비가 주인공을 해치지 않는다 — 주인공은 대상이 아님(Task 3, 4: 적만 맞는지 검사).
5. 집중 중 공격 속도 증가가 집중이 끝나면 원래대로 돌아온다(Task 5 테스트).
