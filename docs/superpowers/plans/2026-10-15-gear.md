# 3-B단계 장비 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 무기·갑옷 드롭과 자동 장착, 장비에 따른 수치·외형 변화.

**Architecture:** sim에 `gear`·`maxTier`와 장비 아이템을 추가하고 주인공 전투 수치를 장비에서 읽는다. 변환 스크립트가 16조합 주인공 시트(공통 칸)와 장비 바닥 그림·아이콘을 만들고, 렌더가 장착 시 해당 시트만 불러온다.

**Tech Stack:** TypeScript, three.js, Vitest, Python + Pillow.

**Spec:** `docs/superpowers/specs/2026-10-15-gear-design.md`

## Global Constraints

- `createWorld` 기본 장비 = `{ weapon: 3, armor: 1 }`(롱소드 8–12·0.8초, 감소 0% = 기존 주인공 수치 → 기존 테스트 유지). 게임 시작 장비는 main이 `{ weapon: 2, armor: 2 }`로 넣는다.
- 장비 드롭 졸개 0.05, 전사 0.12, 무기·갑옷 반반, 단계 `1 + floor(rand × maxTier)`, `maxTier` 기본 2, main이 `min(4, 층 + 1)`.
- 시트 ppm 30, FLARE 커밋 고정, CC-BY-SA 크레딧.

## Review Focus

1. 장비를 바꾼 직후 휘두르는 중이던 공격 → 다음 휘두르기부터 새 간격(진행 중 휘두르기의 attackT가 새 간격을 넘으면 즉시 끝남) (Task 2 테스트).
2. 같은 단계 장비 → 줍지 않고 남음 (Task 2 테스트).
3. 시트 로딩 중 층 이동 → 새 층 주인공도 최종 장비 외형 (Task 3: `setHeroGear`가 마지막 요청만 적용).
4. 사망 재시작 시 그 층에서 얻은 장비는 사라짐 (Task 3 main 로직, 헤드리스).
5. 장비 드롭으로 물약 드롭 확률이 바뀌지 않음 (Task 2: 물약 확률 테스트 그대로 통과).

### Task 2: sim — 장비 수치·드롭·자동 장착

**Files:** `src/sim/world.ts`, `src/sim/world.test.ts`.

**Produces:** `export const WEAPONS = [{ name: '단검', dmg: [4, 7], interval: 0.6 }, …]`(index = tier − 1), `export const ARMORS = [{ name: '천옷', reduce: 0 }, …]`, `World.gear: { weapon: number; armor: number }`, `World.maxTier`, `Item.kind: 'potion' | 'weapon' | 'armor'`, `Item.tier`, `export function attackInterval(w: World, e: Entity): number`, `POTION.drop`와 별개의 `GEAR_DROP = { minion: 0.05, warrior: 0.12 }`.

- [ ] 테스트:

```ts
test('주인공 공격은 무기 수치(데미지·간격)를 따른다', () => {
  for (const tier of [1, 4]) {
    const w = createWorld(3, ['Hw.']);
    w.gear.weapon = tier;
    const m = w.entities[1];
    m.hp = m.maxHp = 1000;
    run(w, Math.round((attackInterval(w, w.entities[0]) * 10) / DT), [{ type: 'attack', targetId: 1 }]);
    const [lo, hi] = WEAPONS[tier - 1].dmg;
    expect(1000 - m.hp).toBeGreaterThanOrEqual(lo * 9);
    expect(1000 - m.hp).toBeLessThanOrEqual(hi * 11);
  }
  const w = createWorld(1, ['H']);
  expect(attackInterval(w, w.entities[0])).toBe(0.8);
  w.gear.weapon = 1;
  expect(attackInterval(w, w.entities[0])).toBe(0.6);
});

test('갑옷은 받는 피해를 줄이되 최소 1', () => {
  const hits = (armor: number) => {
    const w = createWorld(5, ['Hm']);
    w.gear.armor = armor;
    run(w, 600);
    return 100 - w.entities[0].hp;
  };
  expect(hits(4)).toBeLessThan(hits(1));
  expect(hits(4)).toBeGreaterThan(0);
});

test('장비 드롭: 확률, 종류 반반, 단계는 1..maxTier', () => {
  let drops = 0;
  const tiers = new Set<number>();
  const kinds = new Set<string>();
  for (let seed = 1; seed <= 600; seed++) {
    const w = createWorld(seed, ['Hw.']);
    w.maxTier = 3;
    w.entities[1].hp = 1;
    run(w, 60, [{ type: 'attack', targetId: 1 }]);
    for (const it of w.items.filter((i) => i.kind !== 'potion')) {
      drops++;
      tiers.add(it.tier);
      kinds.add(it.kind);
    }
  }
  expect(drops / 600).toBeGreaterThan(0.07);
  expect(drops / 600).toBeLessThan(0.18);
  expect([...tiers].sort()).toEqual([1, 2, 3]);
  expect([...kinds].sort()).toEqual(['armor', 'weapon']);
});

test('더 좋은 장비만 밟으면 장착하고, 같거나 낮은 것은 남긴다', () => {
  const w = createWorld(1, ['H.....']);
  w.gear = { weapon: 2, armor: 2 };
  w.items.push({ id: w.nextItem++, x: 1.5, z: 0.5, kind: 'weapon', tier: 2 });
  w.items.push({ id: w.nextItem++, x: 2.5, z: 0.5, kind: 'weapon', tier: 4 });
  w.items.push({ id: w.nextItem++, x: 3.5, z: 0.5, kind: 'armor', tier: 1 });
  w.items.push({ id: w.nextItem++, x: 4.5, z: 0.5, kind: 'armor', tier: 3 });
  run(w, 90, [{ type: 'move', x: 5.5, z: 0.5 }]);
  expect(w.gear).toEqual({ weapon: 4, armor: 3 });
  expect(w.items.map((i) => [i.kind, i.tier])).toEqual([['weapon', 2], ['armor', 1]]);
});
```

  기존 물약 테스트의 `w.items.push({ id, x, z })`는 `kind: 'potion', tier: 0`을 추가.
- [ ] 실패 확인 → 구현: `createWorld`가 `gear: { weapon: 3, armor: 1 }, maxTier: 2`. `swing`·`startSwing`의 간격은 `attackInterval(w, e)`(주인공 = `WEAPONS[w.gear.weapon - 1].interval`). `damage`: 주인공의 데미지 범위는 무기, 대상이 주인공이면 `max(1, round(dmg × (1 − ARMORS[w.gear.armor - 1].reduce)))`. 몬스터 사망 시 물약 판정(기존) 다음에 `if (rand(w) < GEAR_DROP[kind]) items.push({ kind: rand(w) < 0.5 ? 'weapon' : 'armor', tier: 1 + Math.floor(rand(w) * w.maxTier), … })`. `pickup`: 물약은 기존, 장비는 `tier > w.gear[kind]`이면 장착·제거.
- [ ] 전체 통과 → 커밋 `feat: 장비 수치·드롭·자동 장착`.
