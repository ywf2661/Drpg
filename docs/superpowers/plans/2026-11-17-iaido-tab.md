# 기사 4번째 탭 「발도」 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 기사에 4번째 스킬 탭 「발도」(그어두기·납도·검의 기억·일섬)를 더하고, 적 머리 위 검흔 표시와 지나치는 모션을 만든다.

**Architecture:** 규칙은 `src/sim/iaido.ts`(새 파일)에 모으고 `world.ts`의 시전 표·한 틱·휘두르기에 연결한다. 납도·일섬은 주인공 `phase`의 새 값 `'sheathe'`·`'flash'`(구르기·대지 강타와 같은 방식). 렌더는 sim을 바꾸지 않고 `src/render/marks.ts`(머리 위 HTML)와 `src/render/iaido.ts`(판자 변형·칼선)가 상태를 읽어 그린다.

**Tech Stack:** TypeScript, Vitest, three.js, Vite

**Spec:** `docs/superpowers/specs/2026-11-17-iaido-tab-design.md`

## Global Constraints

- 주석·화면 문구는 한국어(코드 주석은 기존처럼 짧은 평서문).
- `src/sim/`은 three.js·DOM을 쓰지 않고, 난수는 `rand(w)`만(같은 시드 = 같은 결과).
- 기존 검술·돌격·투척 탭과 봇 `BASIC`은 바꾸지 않는다. 기존 `npm test` 전부 통과(밸런스 회귀 포함).
- 수치는 `rules.ts`의 상수 하나에 모은다(아래 값은 설계서의 시작값 그대로).
- **커밋하지 않는다**: 같은 파일들에 사용자의 커밋 안 된 작업(악마 보스 등)이 섞여 있다. 태스크 끝마다 `npm test`·`npm run build`만 확인하고, 커밋은 다 끝난 뒤 사용자에게 묻는다.
- 검사 명령: `npx vitest run <파일>`(태스크), `npm test` + `npm run build`(태스크 끝).

## Review Focus

1. 검흔이 있는 적이 다른 원인(평타·도끼·가시)으로 죽음 → 머리 위 아이콘이 바로 사라진다(Task 5 테스트).
2. 일섬 도중 다음 대상이 이미 죽음 → 건너뛰고, 다 죽었으면 깔끔히 끝나 자동 납도(Task 4 테스트).
3. 일섬 대상 뒤가 벽 → 벽 앞에서 멈추고 다음 대상으로, 주인공이 벽 안에 남지 않는다(Task 4 테스트).
4. 납도 0.25초 동안 주인공이 죽음 → 터지지 않는다(Task 3 테스트).
5. 보스·해골 왕에도 검흔이 새겨지고 터진다(Task 2 테스트).

  - `addMarks(w: World, e: Entity, n: number): void` — 더하고 `markT = memoryStat(w).time`. 주인공 `phase !== 'flash'`이고 개수 ≥ `memoryStat(w).cap`이면 `pop(w, e, 1)`
  - `pop(w: World, e: Entity, mult: number): number` — 검흔 n개를 `skillHit(w, e, markDmg(w, n, mult))`로 터뜨리고 0으로, `blasts`에 `{ kind: 'slash', n }`, `w.impacts`는 `hurt`가 센다. 터진 개수를 돌려준다(0이면 아무것도 안 함)

  - `markStart(w, hero, x?, z?): number` — `cleaveStart`와 같되 `w.slash = 'mark'`, 돌려주는 값 `markStat(w).cd`
  - `markSlash(w: World, hero: Entity): void` — 가르기 타격과 같은 반원(`SKILL.radius`, 앞쪽, `clearLine`), 밀어내지 않음. 적마다: `per = winding(e) ? 2 : markStat(w).per`(**피해 전에** 판정), `skillHit(×markStat.mult)`, 살아 있으면 `addMarks(w, e, per)`. `w.cleaves++`(그림·소리 재사용)
- `swing`: `if (e.skill && hitNow) (w.slash === 'mark' ? markSlash : cleave)(w, e)`
