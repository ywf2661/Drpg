# 바깥 지역 개편 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 초원·설원을 낮의 72×72 들판으로 바꾸고, 계단 대신 가장자리 출구(갈림길)로 넘어가며, 초원은 야영지·설원은 눈보라를 갖게 한다.

**Architecture:** sim(`src/sim`)은 맵 글자에 길 `=`·출구 `F`/`S`·잠긴 상자 `C`를 더하고 `World.exits`·`Chest.guards`를 읽는다. 동굴 입구는 바깥 맵의 `>`(계단, 눌러서 들어감 → 미궁)를 그대로 쓴다. 빛·먼 적 숨김·눈보라는 렌더만(`src/render`). `main.ts`가 출구를 보고 다음 `land`·`from`을 정하고 저장한다.

**Tech Stack:** TypeScript, three.js 0.186, vitest(`npm test` = `node tools/test.mjs`), vite

**Spec:** `docs/superpowers/specs/2026-11-16-outdoor-design.md`

## Global Constraints

- sim은 three.js·`Math.random` 금지, 시드가 같으면 같은 맵(`mulberry`).
- 미궁(`land === 'dungeon'`)의 맵·빛·계단 규칙은 바꾸지 않는다. `generateFloor`의 난수열도 그대로(기존 dungeon 테스트가 지킨다).
- 바깥 맵 크기 `WILD = 72`, 미궁 `SIZE = 48`.
- 시야 `SIGHT = 14`m(눈보라 중 8m), 숨김은 `SIGHT − 2`부터 `SIGHT`까지 서서히.
- 눈보라: 40~60초마다 8초, 앞뒤 1.5초 차오름·걷힘, 시작 2초 전 "눈보라가 몰려온다".
- 한 판·새 회차는 초원 1구역 서쪽에서 시작. 바깥 출구: 같은 지역 1 + 다른 바깥 지역 1, 다음 구역 ≥ 3이면 동굴 입구(`>`) 1. 5구역은 출구 없음.
- 저장 `VERSION` 2, 버전 1은 `land: 'dungeon'`, `from: 'w'`로 읽는다.
- 주석·문구는 한국어, 기존 파일 스타일(짧은 함수, 한 줄 주석) 그대로.

## Review Focus

- 상점에서 "남기"를 고른 뒤 출구 칸에 서 있으면 상점이 매 프레임 다시 열리면 안 된다 → 출구 칸을 벗어났다 와야 다시 열림(Task 5 테스트 대신 수동 확인 항목, main.ts는 테스트가 없다).
- 숨겨진(시야 밖) 적을 마우스로 겨누거나 이름표가 보이면 안 된다 → Task 1에서 hover·이름표도 같은 `sightFade`로 가린다.
- 출구로 나간 직후 죽으면 같은 구역을 같은 `land`·`from`으로 다시(다른 지역으로 새지 않음) → Task 5.
- 동굴 입구 `>`를 지나가기만 해서는 미궁으로 빠지지 않는다(계단 규칙 유지) → Task 3 테스트.
- 야영지 상자를 무리가 살아 있을 때 누르면 아무 일도 없고, 무리가 다 죽으면 같은 클릭으로 열린다 → Task 6 테스트.
