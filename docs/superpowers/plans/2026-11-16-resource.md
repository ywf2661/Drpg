# 기력·마나 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 스킬을 쓰면 줄고 시간이 지나면 차는 자원. 기사·궁수는 기력, 마법사·강령술사는 마나.

**Architecture:** 자원은 sim(`World.res`)에 하나, 종류·최대치·회복·비용은 `rules.ts` 표와 `core.ts` 함수. 스킬 트리(옆 세션 drpg-3e 작업) 위에 얹는다: 그쪽 디스패처 `cast()`가 `id = w.keys[key]`로 스킬을 고르고 `CASTS[id]`가 재사용 대기 초(0 = 안 나감)를 돌려준다. 그 한 곳에 `canAfford(w, id)`(호출 전)와 `pay(w, id)`(`cd > 0`일 때)를 끼운다. HUD는 막대 하나와 버튼 표시.

**선행 조건:** 옆 세션 drpg-3e의 스킬 트리 작업이 끝났다는 메시지를 받은 뒤 시작한다(같은 작업 폴더에서 rules·core·world·bot·hud·main·index.html을 고치는 중). 시작 전에 그쪽 최종 이름(`SkillId`, `SKILLS`, `isPassive`, `TREES`, `w.keys`, `KEY_CD`, `CMD_KEY`, `CASTS`, `rank`)을 코드에서 확인하고, 아래 이름과 다르면 그쪽 것을 따른다.

**Tech Stack:** TypeScript, three.js, vite, vitest. 테스트는 `npm test`(Windows 소문자 드라이브 대처 런처 `tools/test.mjs`). 한 파일만: `npm test -- src/sim/resource.test.ts`.

**Spec:** `docs/superpowers/specs/2026-11-16-resource-design.md`

## Global Constraints

- 재사용 대기는 그대로, 비용이 더해진다. 비용은 스킬이 실제로 나갔을 때만.
- 평타와 구르기(`roll`)·순간이동은 무료. 비용은 스킬 단계와 무관하게 고정.
- 층에 들어갈 때·레벨이 오를 때 가득. 자원은 저장하지 않는다(`save.ts`·`Carry` 무변경).
- 기력: 최대 100 고정, 초당 10. 마나: 최대 100 + 레벨마다 8, 초당 4 + 레벨마다 0.2(레벨 1 기준이 100·4).
- 비용은 스킬마다(`SkillId`). 기본값은 트리 위치: 기력 1단계 20·2단계 30·궁극 45, 마나 25·40·70, 패시브 0. 덮어쓰기는 `COST_OVERRIDE` (Task 2에서 봇으로 조정).
- 막대 색: 기력 초록, 마나 파랑(`--magic`). 모자란 스킬 버튼은 푸르게 어둡게(재사용 대기 그늘과 다르게).
- 글은 한국어, 코드 주석도 한국어(이 저장소 관례).

## Review Focus

1. 자원이 모자란데 키보드로 조준 스킬(Q W E R)을 누름 → 조준을 시작하지 말고 "기력이 부족합니다"/"마나가 부족합니다" 알림(조준했다가 발사 때 조용히 안 나가면 안 됨). → Task 3 Step 4.
2. 한 틱에 스킬 명령 두 개(봇·빠른 연타) → 앞 스킬이 자원을 쓰고 뒤 스킬은 남은 양으로 판정. → Task 1 테스트 `한 틱에 두 스킬`.
3. 재사용 대기 중에 누름 → 스킬이 안 나가고 비용도 안 냄. → Task 1 테스트 `안 나가면 비용 없음`.
4. 레벨업(테스터 모드 레벨 +1 포함) → 즉시 가득, 마나 최대치도 커짐. → Task 1 테스트 `레벨업하면 가득`.
6. 칸에 끼운 스킬을 다른 스킬로 바꿈 → 비용도 새 스킬 것. → Task 1 테스트 `칸을 바꾸면 비용도 바뀐다`.
5. 모바일에서 자원이 모자란 스킬 버튼을 끌기 → 조준 궤적이 뜨지 않음, 탭은 알림. → Task 3 Step 4.

**Interfaces:**
- Produces (`rules.ts`, `world.ts`가 `export *`로 다시 내보냄):
  - `type ResourceKind = 'energy' | 'mana'`
  - `const RESOURCE: Record<HeroClass, ResourceKind>`
  - `const ENERGY = { max: 100, regen: 10 }`, `const MANA = { max: 100, perLevel: 8, regen: 4, regenPerLevel: 0.2 }`
  - `const TIER_COST: Record<ResourceKind, { tier1: number; tier2: number; ultimate: number }>` = 기력 20·30·45, 마나 25·40·70
  - `const COST_OVERRIDE: Partial<Record<SkillId, number>>` (처음엔 비어 있음)
  - `World.res: number`
- Produces (`core.ts`): `resMax(w: World): number`, `resRegen(w: World): number`, `skillCost(cls: HeroClass, id: SkillId): number`(`COST_OVERRIDE` 먼저, 없으면 `SKILLS[id].tier`로 — 0 = 1단계, 1 = 2단계, 2 = 패시브(`isPassive`, 0), 3 = 궁극), `canAfford(w: World, id: SkillId): boolean`, `pay(w: World, id: SkillId): void`
- Consumes (스킬 트리): `SkillId`, `SKILLS[id] = { cls, tab, tier }`, `isPassive(id)`, `TREES[cls]` = 탭 3개 `{ name, skills: [1단계, 2단계, 패시브, 궁극] }`, `w.keys`, `KEY_CD`, `cast()` 디스패처
