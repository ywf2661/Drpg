# 25단계: 긴장감 설계

- 날짜: 2026-11-11
- 목표: "게임이 너무 쉽다"를 푼다. 코드에서 찾은 원인 둘 — 위험을 버튼 하나로 지울 수 있다(즉시 회복 물약, 대가 없는 죽음), 서서 때리는 것이 정답이다(피할 공격이 거의 없다).
- 하지 않는 것: 몬스터 기본 데미지·체력 수치, 레벨업 시 완전 회복, 새 몬스터 그림(26단계), 스킬 구조(이후).
- 실패로 보는 것: 예고가 안 보여서 억울하게 맞는 것, 봇이 못 깨는 난이도, 같은 시드가 다른 결과를 내는 것.
- 수치는 전부 해 보고 조정한다.

## 1. 물약: 서서히 회복 (`world.ts`, `rules.ts`)

마시면 최대 체력의 50%가 `POTION.time = 4`초에 걸쳐 고르게 찬다(합계는 정확히 50%, 정수 단위). 차는 동안에는 다시 마실 수 없다(물약도 줄지 않는다). 죽으면 멈춘다. 상태는 `World.healing = { total, given, t } | null`. 물약 버튼에 스킬처럼 남은 시간 가림막.

## 2. 죽음의 대가: 금화 절반 (`shop.ts`의 `deathGold`, `main.ts`, `bot.ts`)

죽는 순간 그 층에 들어올 때 금화의 절반(내림)을 잃고 바로 저장한다(새로고침으로 피할 수 없게). 다시 시작하면 같은 층을 줄어든 금화로. 배너에 잃은 금화를 보여 준다. 연달아 죽으면 계속 절반.

## 3. 예고 공격 (`abilities.ts`, `rules.ts`)

`World.zones: Zone[]` — 바닥의 위험 구역 `{ id, x, z, r, t, total, dmg, owner }`. 매 틱 `t`가 줄고, 0이 되면 반경 안의 살아 있는 주인공에게 `dmg`(만들 때 굴림). `owner ≥ 0`이면 그 몬스터가 예고 자세(`phase === 'windup'`)를 유지해야 하고, 죽거나 끊기면(함성 기절, 스킬 밀어내기) 구역이 사라진다.

| | 전사 내려찍기(`SLAM`) | 마법사 불기둥(`METEOR`) |
|---|---|---|
| 조건 | 대상이 사거리 안, 대기 끝 | 대상이 사거리 안·시야 트임, 대기 끝 |
| 예고 | 제자리 0.8초(붉게 맥동), 앞 1m 지점 반경 1.3m | 주인공 발밑 반경 1.2m(화염구 폭발과 같음), 1.2초 |
| 피해 | 평타 굴림 × 2 | 평타 굴림 × 1.5, 폭발 기록(그림·소리) |
| 대기 | 6초(처음은 대상을 잡고 2~4초 뒤, id로 엇갈림) | 7초(처음 3~5초 뒤) |
| 끊기 | 함성, 가르기·돌진·도끼의 밀어내기, 처치 | 못 끊음(이미 떨어지는 중). 걸어서 피한다 |

정예 전사도 내려찍는다. 해골 왕·보스는 그대로. `knock`이 예고 자세도 끊도록 `phase: 'none'`을 함께 넣는다(보스·해골 왕은 원래 밀리지 않는다).

내려찍기가 떨어지면 `blasts`에 `kind: 'slam'` 기록(땅 울림 그림·둔탁한 소리). 화염구·불기둥은 `kind: 'fire'`.

## 4. 화면 (`src/render/zones.ts` 새 파일)

구역마다 바닥에 붉은 테두리 원 + 안에서 차오르는 원(진행도 = 1 − t/total). 다 차는 순간 터진다.

## 5. 봇·밸런스 (`bot.ts`, `playthrough.test.ts`)

봇은 구역 안에 있으면 바깥으로 걸어 나간다(판단 주기 0.25초 = 사람의 반응 속도쯤). 체력 60% 아래에서 미리 마신다. 죽으면 금화 절반. 기준은 구현 후 측정해서 새로 잡는다.
