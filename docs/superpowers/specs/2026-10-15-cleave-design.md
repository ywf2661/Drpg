# 8단계: 스킬 — 가르기(Cleave) 설계

- 날짜: 2026-10-15
- 목표: 몬스터 무리에 둘러싸였을 때 쓸 수 있는 범위 공격. 일반 공격(단일 대상)과 선택지를 만든다.
- 결정 사항(추천안 채택): 마나 없이 재사용 대기시간(4초)만, 전방 반원 범위, 무기 데미지 150%, 일반 휘두르기와 같은 동작·시간.

## 1. 규칙 `src/sim/world.ts`

- 명령 `{ type: 'skill'; x?: number; z?: number }`: (x, z)가 있으면 그쪽을 바라보고, 없으면 2.5m 안 가장 가까운 살아 있는 적, 그것도 없으면 현재 방향.
- 조건: 살아 있음, `w.skillCd ≤ 0`. 사용하면 `skillCd = 4`, 이동·대상을 멈추고 휘두르기 시작(`hero.skill = true`).
- 휘두르기의 타격 시점(40%)에 바라보는 방향 기준 **반경 2m·전방 180°(내적 ≥ 0)** 안의 살아 있는 적 모두에게 `굴림 × 1.5`(벽 너머 제외 — 기존 시야 검사). `w.cleaves++`(렌더·소리용 카운터).
- 휘두르기가 끝나면 이어서 휘두르지 않고 멈춘다(`skill = false`).
- `skillCd`는 매 틱 DT씩 감소.

## 2. 입력·HUD

- 우클릭: 커서의 바닥 지점 방향으로 가르기(브라우저 메뉴 막음). `E` / `2` 키: 자동 방향. 모바일: HUD 스킬 버튼(아이콘 22번), 재사용 대기 중에는 남은 시간 비율만큼 어둡게 덮음.

## 3. 그림·소리

- FLARE `powers/cleave`(8방향 6프레임 400ms) 시트 `cleave`, 가르기 순간 주인공 위치·방향에 한 번 재생.
- 소리: `melee_attack_2`를 크게(가르기 전용 이벤트 `cleave`).

## 4. 범위 밖

마나, 여러 스킬, 스킬 레벨·강화.

## 5. 완료 기준

1. `npm test`: 전방 범위 안 적 모두 피해(뒤쪽·범위 밖·벽 너머 제외), 150%, 재사용 대기, 사망 시 불가, 조준 방향, 대상 없이도 사용, 끝나면 멈춤, 소리 이벤트.
2. `npm run build`.
3. 헤드리스: 둘러싼 몬스터에게 가르기 → 여러 마리 피해, 효과 그림, 버튼 대기 표시.
