# 18단계: 회차(New Game+) 설계

- 날짜: 2026-10-16
- 목표: 보스를 잡은 뒤에도 키운 캐릭터로 계속 즐길 수 있게 한다.
- 결정 사항(추천안 채택): 클리어 후 [다음 회차]를 고르면 레벨·장비·물약·금화를 유지하고 1층부터, 몬스터가 회차마다 50%씩 강해진다. [처음부터]도 남긴다.

## 1. 규칙

- 층 배율 `floorPower(층, 회차) = (1 + 0.15 × (층 − 1)) × (1 + 0.5 × 회차)` (회차 0 = 첫 판).
- 보스 배율 `1 + 0.5 × 회차`(`createWorld`의 네 번째 인자 `bossPower`, 기본 1).
- 경험치·금화는 기존처럼 몬스터 배율을 곱하므로 회차가 오를수록 많이 준다.
- 저장에 `cycle`(없으면 0). 기록(시간·처치·사망)은 회차를 이어 누적.

## 2. 화면

- 클리어 배너: [다음 회차 ▶] · [처음부터 (R)].
- 층 표시: 회차가 1 이상이면 "지하 N층 · K회차"(K = 회차 + 1).

## 3. 완료 기준

1. `npm test`: 회차 배율, 보스 배율 인자, 저장 cycle(이전 저장 0·범위 검사).
2. `npm run build`.
3. 헤드리스: 클리어 → 다음 회차 → 1층, 레벨·장비 유지, 몬스터 체력 증가, "2회차" 표시, 저장, 콘솔 오류 없음.
