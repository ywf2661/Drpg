# 6단계: 경험치·레벨 설계

- 날짜: 2026-10-15
- 목표: 몬스터를 잡을수록 강해지는 성장 루프. 층을 내려갈수록 강해지는 몬스터를 레벨로 따라잡는다.
- 결정 사항(추천안 채택): 자동 성장(스탯 분배 없음), 레벨업 시 완전 회복, 층 사이 유지(사망 후 다시 시작하면 그 층 진입 때 레벨·경험치로).

## 1. 규칙 `src/sim/world.ts`

| 항목 | 값 |
|---|---|
| 처치 경험치 | 졸개 10, 전사 25, 보스 0 — × 몬스터 층 배율, 반올림 |
| 다음 레벨까지 | `40 + 30 × (레벨 − 1)` (1→2: 40, 2→3: 70, …) |
| 레벨 효과 | 최대 체력 `100 + 10 × (레벨 − 1)`, 주인공 데미지 × `1 + 0.05 × (레벨 − 1)` |
| 레벨업 | 남는 경험치는 이월, 한 번에 여러 레벨 가능, 체력 완전 회복 |

- `World.level`, `World.xp`(현재 레벨에서 쌓인 양). `createWorld` 기본 레벨 1·경험치 0. `setLevel(w, level, xp)`가 주인공 최대 체력·체력을 맞춘다(main이 층을 만들 때 사용).
- 경험치는 주인공이 아닌 엔티티가 죽을 때 `damage()`에서 지급(누가 죽였든 주인공 몫 — 몬스터끼리는 싸우지 않음).

## 2. 보스 재조정

예상 진행(층마다 전멸 가정)으로 5층 도착 시 약 8레벨. 보스 체력 300 → **600**, 데미지 10–16 → **14–22**. 밸런스 테스트(시뮬레이션)로 고정:
- 8레벨·롱소드·사슬 + 물약 3개 → 대부분 승리
- 8레벨·롱소드·사슬, 물약 없음 → 대부분 패배
- 1레벨·숏소드·가죽 + 물약 4개 → 대부분 패배(레벨을 올려야 함)

## 3. 화면·소리

- HUD: 체력바 아래 얇은 경험치 바(노란색) + 체력바 왼쪽 위에 `Lv N`.
- 레벨업: 알림 "레벨 업! Lv N", FLARE `level_up.ogg`.

## 4. 범위 밖

스탯 분배, 스킬, 레벨 표시 몬스터, 경험치 손실 페널티.

## 5. 완료 기준

1. `npm test`: 경험치 지급량(배율), 레벨업 경계·이월·여러 레벨, 최대 체력·데미지 반영, 완전 회복, `setLevel`, 보스 밸런스 3조건, 레벨업 효과음 이벤트.
2. `npm run build`.
3. 헤드리스: 몬스터 처치로 경험치 바 증가, 레벨업 알림, 층 이동 후 유지, 사망 재시작 시 복원.

## 6. 밸런스 조정(봇 플레이 테스트 후)

`src/sim/playthrough.test.ts`: 단순한 봇이 1~5층을 시드 6개로 플레이(층마다 최대 4번 시도). 처음 수치로는 1/6만 클리어(4·5층에서 막힘).
- 몬스터 데미지에는 층 배율의 **절반**만 적용(체력에는 전부). 둘 다 곱하면 난이도가 배율의 제곱으로 오른다.
- 층 배율 `1 + 0.2 × (층 − 1)` → **`1 + 0.15 × (층 − 1)`** (`floorPower`).
- 보스 600 → 500, 데미지 14–22 → 12–20.
- 결과: 4/6 클리어, 총 사망 12, 클리어 시 레벨 9~10. 이 기준을 테스트로 고정(이후 맵 무작위성 편차 때문에 시드 10개·클리어 ≥ 7·사망 합 ≤ 25·레벨 ≥ 5로 바꿈).

## 7. 2차 밸런스(2026-10-16, 마법 옵션·스킬 4개 이후)

- 봇이 스킬 4개를 쓰도록 바꿈(무리면 가르기, 둘러싸이거나 보스 예고면 함성, 멀리서 쏘는 적엔 도끼·돌진). 피하기는 안 함.
- 측정: 기존 수치로는 스킬 없이도 10/10 클리어·사망 5 → 너무 쉬움(마법 옵션 효과).
- 공통 배율을 올리면 1~2층에서 레벨이 낮은 판이 막혀(시드 1, 2층 Lv3) 초반이 가혹해짐 → 대신 **데미지에 반영하는 층 배율 비율 `DMG_SCALE` 0.5 → 2**(1~2층 거의 그대로, 5층 ×1.3 → ×2.2). 정예 데미지 1.3 → 1.15.
- 결과: 스킬 사용 10/10·사망 4, 스킬 없이 10/10·사망 13.
- 테스트 기준: 스킬 사용 9판 이상·사망 15 이하, 스킬 없이 사망 8 이상(너무 쉬워지면 걸림), 스킬 사용이 더 적게 죽음.
