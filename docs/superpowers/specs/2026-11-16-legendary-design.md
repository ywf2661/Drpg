# 전설·세트 장비, 스킬 +N 옵션 설계

- 날짜: 2026-11-16
- 요청: "아이템 파밍 기획. 특수 에픽템 같은 거. 재미가 있어야 해." → "빌드가 완성되는 쾌감도 중요하고, 스킬 레벨 +1 같은 옵션도 좋지 않을까?" → "A로 하고, 장비 세트는 일단 한 세트만." → "특출난 전설 몇 개는 입었을 때 원색으로 차별화. 층 이동 때 기본 장비 업그레이드(상점 강화)는 뺀다."
- 목적: **빌드가 완성되는 쾌감.** 장비를 하나씩 맞춰 갈수록 주력 스킬이 눈에 띄게 세지고 모양이 바뀌며, 마지막 조각이 들어오는 순간 "됐다"가 나와야 한다.

## 지금 상태

- 장비 4부위(무기·갑옷·투구·장화), 단계 1~4, 등급 일반·마법·희귀(옵션 0·1·2개). 옵션 9종은 전부 숫자(`AFFIXES`).
- 보관함 10×4 격자, 자동 장착(점수 비교), 상점 강화·팔기. 직업을 고르면 보관함이 빈다(`startOf`) — 장비는 늘 지금 직업의 것.
- 스킬: 직업당 탭 3개 × [1단계, 2단계, 패시브, 궁극], 포인트로 최대 5단계(`RANK_MAX`), 5단계 완성 효과(`mastered`), 같은 탭 시너지(`syn`). 모든 스킬 효과가 `rank()`(`src/sim/core.ts`)로 단계를 읽는다.
- 문제: 희귀 장비도 숫자만 조금 오른다. 장비를 바꿔도 플레이가 안 바뀐다.

## 목표 · 비목표 · 실패 기준

- 목표: 스킬 +N 옵션으로 주력 스킬을 5단계 너머(초월)까지 키운다. 전설 하나가 스킬 하나의 모양을 바꾼다. 세트 4부위를 모으면 싸우는 법이 바뀐다.
- 비목표(2차 이후): 직업별 전설 추가, 지역 보스별 전설 표, 전설 도감, 세트 여러 개, 저주받은 장비, 분해·조각, 효과 추출(큐브).
- 실패 기준(돌아가도 실패):
  - 전설이 숫자만 올린다.
  - 전설이 흔해서 떨어져도 설레지 않는다, 또는 너무 드물어 한 판에 하나도 못 본다.
  - 자동 장착이 전설·세트를 멋대로 벗겨 빌드를 망친다.

## 접근

- **고른 것(A): 스킬 +N 옵션 + 전설 효과를 묶는다.** 전설마다 고유 효과 1개와 그 효과에 맞는 스킬 보너스가 고정으로 붙는다. 스킬 보너스는 `rank()` 한 곳에서 더해 데미지·재사용 대기·완성 효과·시너지가 모두 따라온다. 여기에 세트 하나.
- 버린 것(B 전체): 직업마다 세트 — 세트 4개 × 4부위의 이름·효과. 사용자가 "한 세트만"으로 정했다. 공용 세트 하나로 시작한다.
- 버린 것(C): 전설 효과를 뽑아 따로 끼우기 — 추출 창·영구 보관이 필요하고, 전설이 쌓인 뒤에야 의미가 있다.

## 1. 스킬 +N 옵션

| 옵션 | 표시 | 값 | 나오는 곳 |
|---|---|---|---|
| 스킬 하나 | `가르기 +1` | 1~2 (2는 희귀·전설에서 25%) | 마법·희귀의 옵션 후보 하나로 추가(다른 옵션과 같은 확률), 모든 부위 |
| 탭 전체 | `검술 스킬 +1` | 1 | 희귀가 옵션을 굴릴 때 15%로 그중 하나를 이것으로 / 전설 고정 |
| 모든 스킬 | `모든 스킬 +1` | 1 | 전설 고정만 |

- 대상 스킬·탭은 지금 직업(`w.cls`)의 `TREES`에서 굴린다. 패시브도 대상(패시브 단계도 수치를 올린다).
- **배운 스킬에만 붙는다.** 기본 단계가 0이면 보너스도 0(장비로 스킬이 생기지 않는다 — 단축키·트리 규칙이 꼬인다).
- **초월:** 실제 단계 = `min(기본 + 장비 보너스, RANK_MAX + 2)`. 포인트로는 여전히 5단계까지(`learn`은 기본 단계로 검사). 장비로 6·7단계.
- 장비를 벗으면 단계가 내려간다. 재사용 대기·자원은 그대로 둔다(일시정지 중 맞바꿈 악용 여지 없음).

### 데이터

- `Affix`에 대상 칸: `{ kind: 'skill'; value; skill: SkillId } | { kind: 'tab'; value; tab: 0|1|2 } | { kind: 'allSkills'; value }` (기존 9종은 그대로).
- `rank(w, id)`: `w.ranks[id]`가 0이면 0, 아니면 위 식. 장비 보너스는 `w.mods` 네 부위 + 고유 장비 고정 보너스의 합.
- 기본 단계가 필요한 곳(`learn` 상한, 스킬 창의 "다음 단계") — `baseRank`를 따로 둔다.

### 6·7단계 수치

- 스킬 수치 함수는 대부분 `x = 단계 − 1`의 1차식이라 그대로 늘어난다. 재사용 대기처럼 줄어드는 값은 0 이하·비정상이 될 수 있다(예: 함성 `15 − x`).
- 규칙: 모든 스킬 수치 함수가 7단계에서 **재사용 대기 ≥ 5단계 값의 60%, 양수**, 범위·시간 양수. 넘는 식은 바닥값을 둔다.
- 테스트: 직업 4개 × 스킬 12개를 7단계로 놓고 모든 `*Stat` 함수가 위 조건을 만족.

### 화면

- 스킬 창: `가르기 4 (+2) → 6` — 장비 보너스는 초록, 6·7단계는 금색 "초월". 다음 단계 설명은 기본 단계 기준.
- 장비 이름표·보관함 옵션 줄: `가르기 +2`, `검술 스킬 +1`, `모든 스킬 +1`. 아직 안 배운 스킬이 대상이면 회색 + "(배우지 않음)".

## 2. 전설 (주황)

- 고유 이름, **고유 효과 1개 + 고정 스킬 보너스 + 무작위 옵션 1~2개**(희귀처럼 굴림, 스킬 옵션 포함). 같은 전설도 옵션에 따라 좋고 나쁨이 갈려 다시 파밍할 이유가 남는다.
- 단계는 드롭 단계를 따르고 바뀌지 않는다(상점 강화를 없앤다 — §6). 같은 전설도 높은 단계를 다시 노릴 이유가 된다. 외형은 단계 그림 그대로, 특출난 몇 개만 원색(§2-1).

### 1차 목록 (8개: 직업 4 + 공용 4)

| 이름 | 부위 | 직업 | 고유 효과 | 고정 보너스 |
|---|---|---|---|---|
| 돌아오는 도끼날 | 무기 | 기사 | 도끼 던지기의 도끼가 최대 거리(또는 벽)에서 주인공에게 돌아오며, 돌아오는 길에 다시 맞힌다 | 도끼 던지기 +2 |
| 쪼개지는 구슬 | 무기 | 마법사 | 화염구가 터지면 작은 화염구 3개가 사방으로 퍼진다(굴림 ×0.4) | 화염구 +2 |
| 매의 눈 두건 | 투구 | 궁수 | 관통 사격이 벽에 닿으면 한 번 튕긴다 | 관통 사격 +2 |
| 뼈 왕의 수의 | 갑옷 | 강령술사 | 해골 병사 최대 수 +2, 해골 병사가 쓰러지면 그 자리가 터진다(해골 굴림 ×1.5) | 해골 병사 +2 |
| 결투자의 투구 | 투구 | 공용 | 받아치기(예고 중인 적을 스킬로 맞힘) 성공 시 모든 스킬 재사용 대기 −1초, 기력·마나 +15 | 탭 하나 +1(드롭 때 굴림) |
| 불꽃 걸음 | 장화 | 공용 | 구른 길에 2초 동안 불길(돌진 불길과 같은 장치) | 탭 하나 +1 |
| 광전사의 손잡이 | 무기 | 공용 | 잃은 체력 비율만큼 공격 속도·스킬 피해 증가(최대 +40%) | 1단계 스킬 하나 +1 |
| 왕관 없는 왕의 망토 | 갑옷 | 공용 | 최대 체력 −15% | 모든 스킬 +1 |

- 직업 전설은 그 직업일 때만 떨어진다. 공용은 누구나.

### 2-1. 원색 외형 (특출난 4개)

그림은 그 단계의 장비 그대로, **그 부위 레이어만 원색으로 물들인다.** 멀리서도 "저 사람 전설 입었다"가 보이게.

| 전설 | 부위 레이어 | 색 |
|---|---|---|
| 왕관 없는 왕의 망토 | 갑옷(chest·lower·off) | 노랑(금) `#f5c400` |
| 쪼개지는 구슬 | 무기(main) | 빨강 `#e8261c` |
| 매의 눈 두건 | 투구(head) | 초록 `#1fb83c` |
| 결투자의 투구 | 투구(head) | 파랑 `#1f5fe8` |

- `UNIQUES[id].look?: string`(색). 없으면 평소 외형.
- 칠하는 법(`src/render/sprites.ts`의 `heroSheet`): 레이어 그림을 작은 캔버스에 그리고 `globalCompositeOperation = 'color'`로 색을 덮은 뒤 `'destination-in'`으로 원래 그림의 투명도를 되살린다 — 명암은 남고 색만 원색. 물들인 레이어는 `url + 색`으로 캐시.
- `setHeroGear(g, cls, looks)`: `looks: Partial<Record<Slot, string>>`, 조합 키에 색을 넣는다.
- 바닥·보관함 아이콘은 그대로(등급 색 이름표로 충분).
- 효과 수치는 시작값. 봇으로 조정.

## 3. 세트 — 정예 사냥꾼 (초록)

공용 세트 하나. 정예를 잡을수록 세지고, 세질수록 정예를 더 만나는 파밍 고리.

| 부위 | 이름 | 고정 옵션 |
|---|---|---|
| 무기 | 정예 사냥꾼의 <무기 이름> | 데미지 +20% |
| 갑옷 | 정예 사냥꾼의 흉갑 | 최대 체력 +25 |
| 투구 | 정예 사냥꾼의 가면 | 탭 하나 +1 |
| 장화 | 정예 사냥꾼의 장화 | 이동 속도 +8% |

- 조각마다 고정 옵션 1개 + 무작위 옵션 1개.

| 모은 수 | 효과 |
|---|---|
| 2부위 | 정예·보스에게 주는 피해 +25%. 정예를 잡으면 기력·마나 +30 |
| 4부위 | **정예를 잡으면 20초 동안 그 정예의 특성을 내가 얻는다.** 서로 다른 특성은 겹치고, 같은 특성은 시간이 다시 20초 |

4부위로 얻는 특성:

| 특성 | 주인공이 얻는 것 |
|---|---|
| 신속한 | 이동 ×1.35, 공격 속도 ×1.25 (`ELITE_FX` 그대로) |
| 흡혈의 | 준 피해의 10% 회복 |
| 폭발하는 | 내가 잡은 적이 그 자리에서 바로 폭발(반경 1.2m, 굴림 ×1.5) — 무리를 연쇄로 터뜨린다 |
| 통솔하는 | 나와 아군(해골 병사)의 데미지 ×1.3 |
| 분열하는 | 내가 잡은 적 자리에 10초짜리 해골 병사 1마리(최대 3, 강령술사의 해골과 같은 장치) |

- 보이는 것: 얻은 특성마다 발밑 고리(정예 고리 그대로, 특성 색), HUD에 특성 아이콘과 남은 시간. 세트 효과 발동 순간 "정예 사냥꾼 4/4" 알림.
- 보관함·이름표에 세트 진행 `정예 사냥꾼 (2/4)`, 툴팁에 세트 효과(입은 수만큼 켜진 줄은 밝게).

## 4. 드롭

| 어디서 | 고유 장비 확률 |
|---|---|
| 정예 | 6% + 운 보정 (구현 때 3%에서 올림 — §10) |
| 해골 왕·미노타우르스·지역 보스 | 25% |
| 보물 상자 | 1% |

- 고유 판정에 성공하면 전설 60% / 세트 조각 40%. 세트 조각은 **입지도 보관함에 있지도 않은 부위**를 70%로 고른다(모으는 길을 짧게).
- 전설은 지금 직업이 쓸 수 있는 목록(직업 전설 + 공용)에서 고르게.
- **운 보정:** 정예를 잡고 고유 장비가 안 나올 때마다 +1%p(구현 때 0.5에서 올림), 나오면 0. 저장에 넣는다(`legendPity`). 사망 때는 그 층에 들어올 때 값으로.
- 단계: 정예 드롭과 같이 `w.maxTier`.
- 튜닝 목표: 봇 기준 한 판(5층)에 고유 장비 평균 1~2개, 세트 4부위 완성은 3~5판에 한 번. `playthrough.test.ts`처럼 시드 30판으로 잰다.

### 떨어지는 순간

- 주황(전설)·초록(세트) **빛기둥**(새 그림 1개: 위로 긴 반투명 판자, 색만 바꿈), 전용 효과음(`level_up` 재사용 가능), 0.3초 멈춤(타격감의 멈춤 장치).
- 자동 지도에 주황·초록 점. 바닥 이름표는 등급 색.

## 5. 장착 · 자동 장착

- 자동 장착은 **고유 장비를 입히지도 벗기지도 않는다.** 고유 장비는 보관함으로 들어가고, 고르는 건 플레이어(빌드를 고르는 순간). 입은 고유 장비 위로 점수 높은 일반 장비가 와도 보관함으로.
- 장비 점수에 스킬 보너스 반영: 해당 부위 점수 × `(1 + 0.08 × 지금 직업에서 배운 스킬에 붙은 보너스 단계 수)`. 점수는 일반 장비끼리 비교와 보관함 ▲/▼에 쓴다.
- 봇: 자동 장착을 그대로 쓰므로 고유 장비를 안 입는다(밸런스 기준이 흔들리지 않는다). 봇은 보관함의 고유 장비를 팔지 않는다(튜닝 측정용으로 개수만 센다).

## 6. 저장 · 상점

- 고유 장비 표식은 옵션 목록 안의 특수 옵션 `{ kind: 'unique', value: 0, u: UniqueId }`(구현 때 정함: 장착·보관함·층 이동·저장이 지금 코드 그대로 따라온다). 고정 보너스도 옵션으로 들어간다.
- 저장 버전 올림. 검증: 고유 ID가 표에 있고 부위가 맞음, 스킬 옵션의 스킬이 그 직업 `TREES`에 있음, 탭 0~2, 값 범위, 옵션 수(고유는 고정 보너스 제외 최대 2). 이상하면 지금 정책대로 저장 전체를 버린다. 이전 저장은 고유 없음·운 보정 0으로 읽는다.
- **상점 강화 삭제.** 상점은 물약 사기와 팔기만. `shop.ts`의 `UPGRADE`·`buy`의 장비 분기·`offers`의 장비 줄, HUD 강화 줄, 봇의 강화 구매를 지운다. 장비 단계는 드롭으로만 오른다. 봇이 약해지므로 `playthrough.test.ts` 기준을 다시 잰다 — 너무 어려워지면 드롭 단계(`GEAR_DROP`, `maxTier`)를 올려 맞춘다(강화를 되살리지 않는다). 금화는 물약에만 쓰여 남는다 — 쓸 곳은 2차.
- 팔기: 고유 장비 `sellPrice` + 100(팔기 전 확인 창 "전설을 팝니다").

## 10. 구현 결과 (2026-11-16)

구현하면서 정한 것:

- **저장 버전은 올리지 않았다.** 새 옵션은 검증만 넓히면 되고, 이전 저장은 그대로 읽힌다(운 보정 없으면 0).
- **돌아오는 도끼날은 나갈 때도 꿰뚫는다.** 맞으면 사라지는 보통 도끼로는 "돌아오며 다시 맞힌다"가 일어나지 않는다. 끝(또는 벽)에서 주인공에게 돌아오며 맞은 적을 다시 맞힌다.
- **쪼개진 작은 화염구**는 폭발 중심에서 0.8m 떨어져 나간다(맞은 적에게서 바로 다시 터지지 않게), 비행 거리는 화염구의 1/3.
- **불꽃 걸음**은 마법사의 순간이동 길에도 불길을 놓는다.
- **4부위 특성의 주인공 발밑 고리**는 미뤘다. HUD(체력 막대 위 오른쪽)에 특성 이름·남은 초를 특성 색으로 띄운다.
- **7단계 수치**: 모든 스킬 수치 함수가 바닥값 없이 기준(재사용 대기 ≥ 5단계의 60%, 확률·감소율 ≤ 0.9)을 지켰다(`legend.test.ts`).

### 밸런스 (봇 30판, 스킬·구르기, 클리어 / 사망 합계, 판당 고유 장비)

| | 변경 전 | 강화만 삭제 | 드롭 단계 층 + 2 | **채택: 정예·해골 왕 장비 +1단계** |
|---|---|---|---|---|
| 기사 | 18 / 105 | 20 / 107 · 0.60 | 20 / 91 · 0.77 | **18 / 105 · 0.70** |

| 강령술사 | 21 / 85 | 20 / 95 · 0.67 | 21 / 91 · 0.90 | **21 / 88 · 0.87** |

- 강화만 지우면 마법사가 크게 약해졌다. 층 + 2는 기사·궁수가 "너무 쉬움" 기준(`playthrough.test.ts`)에 걸렸다. 채택안: 층의 드롭 단계는 그대로(층 + 1), **정예·해골 왕 장비만 한 단계 위**(최대 4) — "정예를 잡아야 장비가 오른다".
