# 4단계: 보스(미노타우르스) 설계

- 날짜: 2026-10-15
- 목표: 5층 끝에 보스를 두고, 보스를 쓰러뜨리면 클리어(기존 "5층 전멸 = 클리어"를 대체). 장비·물약을 모아 내려간 보람이 생기게 한다.
- 결정 사항(추천안 채택): FLARE 미노타우르스 그림, 특수 공격 없는 강한 근접 몬스터(처음 보스로 단순하게), 상단 보스 체력바, 5층 제목에 보스 이름.

## 1. 보스

| 항목 | 값 |
|---|---|
| 이름 | 미노타우르스 (`kind: 'boss'`, 맵 글자 `M`) |
| 체력 | 300 × 층 배율(5층 1.8 → 540) |
| 데미지 | 10–16 × 층 배율(갑옷으로 감소) |
| 공격 간격 | 1.6초 |
| 이동 속도 | 2.4m/s |
| 드롭 | 없음(처치 = 클리어) |

AI는 다른 몬스터와 같다(8m 안에 들어오면 추적·공격).

## 2. 맵 생성

- 5층(계단 없는 층)에서는 계단 대신 **주인공에서 걸어서 가장 먼 방의 중심에 `M`**. 소품은 계단과 같은 규칙으로 보스 칸 주변 3칸을 비운다.
- 일반 몬스터 수·구성은 그대로(보스 방에도 섞일 수 있음 = 호위).

## 3. 규칙

- `outcome`: 사망 → 계단 층은 기존 → 보스가 있는 층은 **보스가 죽으면 `clear`**(다른 몬스터가 살아 있어도) → 보스 없는 층은 기존(전멸).
- 보스도 `Kind`라서 STATS·드롭 표에 항목이 생긴다(드롭 확률 0).

## 4. 그림·화면

- `tools/sprites.py`: FLARE `enemies/minotaur`(동작마다 다른 이미지, 정의 파일의 프레임 줄 끝에 이미지 이름). 동작 `stance run swing hit die`, 사망은 마지막 프레임에 멈추도록 `play_once`. 시트가 4096px을 넘지 않는 배율 `BOSS_SCALE`(기본 0.32, 넘으면 낮춤).
- 상단 가운데 보스 체력바(`#boss`, 이름 + 막대): 보스가 살아 있고 주인공과 12m 이내면 표시. 기존 대상 체력바는 그 아래.
- 5층 진입 제목: "지하 5층 — 미노타우르스". 클리어 문구: "미노타우르스를 쓰러뜨렸습니다!".

## 5. 범위 밖

보스 특수 공격·단계 전환, 보스 전용 음악, 보스 드롭, 새 일반 몬스터.

## 6. 완료 기준

1. `npm test`: 5층에만 `M` 1개(먼 방, 걸어서 15칸 이상), `createWorld`가 보스 체력·배율 적용, 보스 처치 = clear(다른 몬스터 생존 무관), 보스 없는 층 기존 규칙 유지, boss 시트 계약.
2. `npm run build` 성공.
3. 헤드리스: 5층 시작 시 제목, 보스 근처에서 보스 체력바, 보스 처치 후 클리어 문구, 콘솔 오류 없음.
