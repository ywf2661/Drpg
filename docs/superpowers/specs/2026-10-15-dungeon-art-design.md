# 2-B단계: FLARE 던전 그림·화로 조명·소품 설계

- 날짜: 2026-10-15
- 목표: 코드로 만든 돌 질감과 임시 계단(검은 구멍)을 FLARE 던전 타일셋 그림으로 바꾸고, 화로 불빛과 소품으로 디아블로 1풍 분위기를 만든다.
- 결정 사항: 벽은 3D 상자를 유지하고 FLARE 벽돌 면을 펴서 질감으로 사용. 큰 소품(화로·통·상자·궤짝·석상)은 칸을 막고 뼈·잔해는 지나감. 화로는 방 절반 정도에 1개씩, 주변 약 4.5m를 밝혀 멀리서도 불빛과 그 옆 몬스터가 보임.
- 원본: `mods/fantasycore/tilesetdefs/tileset_dungeon.txt` + `images/tilesets/tileset_dungeon.png`, 같은 커밋 `af6eee6d…`(CC-BY-SA 3.0).

## 1. 축척과 투영

FLARE 타일은 2:1 아이소(= 내려다보는 각 30°, 우리 카메라와 같음). **FLARE 타일 1개 = 우리 칸 1개(1m)**로 맞춘다.

- 화면에서 1m 칸의 마름모 가로 = √2 × 30px = 42.4px → 타일·소품 축소 비율 `TILE_SCALE = 42.43 / 192 ≈ 0.221`.
- 캐릭터는 기존 0.32 그대로(타일 대비 원작보다 약 1.45배 크게 보임. 허용).
- 화면 기준: 칸의 (최소 x, 최소 z) 꼭짓점 = 마름모 위, +x = 오른쪽 아래, +z = 왼쪽 아래.

## 3. 맵 생성 `src/sim/dungeon.ts`

새 글자: `B` 화로(막음), `o` 큰 소품(막음), `,` 잔해(바닥). 계단·주인공 배치 뒤, 몬스터 배치 전에 꾸민다.

- 놓을 수 있는 칸: 방 안의 `.` 칸, 계단과 체비셰프 거리 3 이상, 주인공과 2 이상.
- 막는 소품(`B`, `o`)은 **방 가장자리 칸**(방 밖 4방향 이웃이 모두 `#`, 즉 복도 입구가 아님)에만, 그리고 놓은 뒤 모든 비벽 칸이 여전히 서로 이어질 때만 둔다(BFS, 실패하면 되돌림).
- 화로: 방 순서를 섞어 `ceil(방 수 / 2)`개 방에 1개씩.
- 큰 소품: 방마다 0~3개. 잔해: 방마다 0~3개(방 안 어디든).
- 결과 검사(테스트): 화로 1개 이상, 계단·주인공 주변 규칙, 막는 소품을 벽으로 쳐도 모든 칸 연결, 기존 조건 유지.

## 4. sim `src/sim/world.ts`

- `createWorld`: `B`·`o`는 막힌 칸, `,`는 바닥. `world.props: { kind: 'brazier' | 'prop' | 'debris'; x: number; z: number }[]`(칸 좌표). sim 규칙은 쓰지 않고 렌더용으로만 넘긴다.

## 5. 렌더

### 5.1 바닥·벽 `src/render/render.ts`

- 바닥: 변형 8개마다 `InstancedMesh` 1개(질감 1장 공유, clone으로 offset만 다르게). 칸 좌표 해시로 변형 선택: 80% 평바닥 4종, 20% 금 간 바닥 4종.
- 벽: 상자(1 × 1.2 × 1)에 재질 배열 — +x 면·+z 면은 FLARE 벽돌, 윗면은 `floor.png`의 바닥 19를 어둡게(색 0.35배). 보이지 않는 −x·−z·아래 면은 +x 면 재질 공유. 소품 칸은 벽 상자를 그리지 않는다.
- 질감: Nearest 필터, SRGB, MeshStandardMaterial(횃불·화로 빛을 받음).

### 5.2 소품·계단 `src/render/props.ts`(새 파일)

- 소품: 기존 `cardGeometry`(발 위는 세우고 아래는 눕힘)를 그대로 사용하는 세로 판자. 칸 좌표 해시로 같은 종류 안의 변형 선택(화로는 1종).
- 화로: 8프레임 반복, 화로마다 시작 위상을 다르게. 항상 최대 밝기(불 자체가 광원).
- 잔해·계단: 깊이를 쓰지 않고 캐릭터보다 먼저 그린다(시체와 같은 처리).
- 계단: 4×4칸 판자, 계단 칸 중심에 놓는다.
- 시트 로딩·`cardGeometry`·`frameAt`은 `sprites.ts`에서 공유(시트 정보 타입의 동작 이름을 문자열로 일반화).

### 5.3 조명

- 화로마다 `PointLight(0xff7a30, 강도 18, 거리 4.5, 감쇠 1.5)`, 높이 1.2m, 그림자 없음(벽 너머로 약간 샘. ponytail 주석), 화로마다 다른 위상으로 깜빡임.
- 스프라이트 밝기(캐릭터·소품·계단) = max(횃불 항, 각 화로 항). 화로 항 = `clamp(1 − d / 4.5, 0, 1)^1.4 × 1.0`, 색은 같은 횃불색.

## 8. 완료 기준

1. `python tools/sprites.py` 자체 검사 통과, 새 결과물 생성.
2. `npm test` 통과: 생성기 테스트 확장(화로 수, 소품 위치 규칙, 소품을 막힘으로 본 연결성), `createWorld`의 `props`·막힘, props/stairs 시트 계약 테스트.
3. `npm run build` 성공.
4. 헤드리스 Chrome: FLARE 바닥·벽돌 벽, 화로 불빛(애니메이션), 소품, 계단 그림이 보이고, 소품 칸은 지나갈 수 없으며, 계단으로 내려가기가 그대로 동작. 콘솔 오류 없음.
