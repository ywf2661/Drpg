# 기사 검술 탭 개편: 내리베기 · 거인의 칼

- 날짜: 2026-11-25
- 계기: 사용자 "가르기 탭에 처형 대신 넣을 만한 스킬 추천해 줘" → 회오리도 디아블로 휠윈드를 닮아 함께 바꾸기로
- 상태: 설계(사용자 승인 — "승인띠")
- 그림: 움직이는 그림을 사용자가 보고 "괜찮다"고 했다(https://claude.ai/artifact/7A91nLMnwhFptjZj4xLVQx)

## 왜 바꾸나

- **회오리**는 디아블로의 휠윈드를 그대로 따라 한 느낌이다.
- **처형**은 한 명만 베는 스킬이라 무리를 상대하는 검술 탭과 맞지 않는다.
- 사용자가 고른 방향: **묵직한 힘**(한 방 한 방이 크고 무겁다). 꼭 살릴 것: **보스를 상대할 수 있을 것**.

## 목표 / 하지 않는 것 / 실패로 보는 것

- 목표: 검술 탭이 "빠르고 넓게 베는 가르기 + 힘을 모아 크게 베는 내리베기 + 모든 베기가 무거워지는 궁극기"로 묶인다.
- 하지 않는 것:
  - 가르기와 시체 폭발은 그대로 둔다(시체 폭발 설명의 스킬 이름만 바꾼다).
  - 땅을 내려찍는 계열은 넣지 않는다. 돌격 탭의 대지 강타와 겹친다.
- 실패로 보는 것:
  - 회오리나 처형을 배운 기존 저장 파일을 못 읽는다.
  - 내리베기를 모으다가 졸개에게 맞아 끊긴다(사용자: "안 끊겨야지").
  - 키를 누르고 있는 동안 키 반복 입력 때문에 저절로 베어 버린다.
  - 디아블로의 특정 스킬처럼 보인다.

## 고른 방식(대화에서)

| 결정 | 고른 것 | 버린 것 |
|---|---|---|
| 방향 | **묵직한 힘, 보스 상대 가능** (사용자) | 정통 검술, 어둡고 기괴함, 빠르고 화려함 |
| 2번 칸 | **내리베기**: 모았다가 일직선으로 내리베기 | 도륙(가르기 연타), 칼바람, 후려치기, 칼 꽂기 |
| 궁극기 | **거인의 칼**: 몇 초 동안 칼이 커진다 | 처형 유지, 시체 휘두르기, 핏자국 잇기, 받아넘기기 |
| 모으는 중 맞으면 | **끊기지 않는다** (사용자) | 보스 공격에만 끊김 |
| 코드 이름 | **새 이름(`downcut`·`greatsword`) + 저장 파일 옮기기** (사용자, A안) | 옛 이름(`whirl`·`execute`) 그대로 두고 내용만 바꾸기: 빠르지만 이름과 동작이 어긋나 계속 헷갈린다 |

## 내리베기 `downcut` (검술 2번 칸 `TREES.knight[0][1]`, 회오리 자리)

**누르면 칼을 뒤로 젖혀 힘을 모으고, 떼면 앞으로 일직선으로 내리벤다.**

- 등급·비용·배우는 레벨: 회오리와 같다(트리 2번 칸).
- 쓰는 법:
  - 칸 키를 누르면 모으기 시작. **같은 키를 떼거나 한 번 더 누르면** 벤다.
  - 터치 버튼은 한 번 탭하면 모으고 다시 탭하면 벤다.
  - 비용은 벨 때 낸다. 모으는 사이 기력이 모자라져도 벤다(모으기 상태에 갇히지 않게).
  - sim에서는 같은 명령이 한 번 더 들어오면 "벤다"로 받는다. 그래서 봇과 키보드·터치가 모두 같은 길을 탄다.
  - 키를 누르고 있을 때 나오는 반복 keydown(`e.repeat`)은 무시한다.
- 방향: 벨 때 커서 쪽(마우스가 없으면 가까운 적, 그것도 없으면 바라보는 방향). 모으는 동안 주인공은 그쪽을 바라본다.
- 모으기:
  - 최대 1.5초(5단계는 1초). 다 모인 뒤 1초를 더 들고 있을 수 있고, 지나면 저절로 벤다.
  - 모으는 동안 **천천히만 걷는다**(이동 속도 ×0.4). 평타는 하지 않는다.
  - **맞아도 끊기지 않는다.**
  - 구르기는 모으기를 취소한다. 이때 재사용 대기는 돌지 않는다(내 판단).
- 베기:
  - 모은 정도 p(0~1)에 따라 길이 2m → 6m(단계마다 +0.3m), 폭 1.2m.
  - 배율 1.2 → 4.0(단계마다 +0.3), 시너지 적용.
  - 벽에 막히지 않은 적 모두가 맞는다.
  - 밀어내기: 가르기 거리(0.9m)에서 다 모으면 2m까지. 무거운 적(`heavy`)은 밀리지 않는다.
  - 다 모은 베기에 맞은 무거운 적은 **휘청인다**(기절 0.5초). 같은 적은 2초 안에 다시 휘청이지 않는다.
  - 받아치기 ×2는 기존 `skillHit`이 그대로 붙인다(예고 중인 적).
- 재사용 대기: 벤 순간부터 6초(단계마다 −0.4초).
- 다른 스킬과의 연결:
  - 시체 폭발: 내리베기로 죽은 적이 터진다.
  - 벼림: 벨 때 충전 하나를 쓴다(`temper`).
  - 칼의 여운: `SLASHES`·`TAKES`에 넣는다. 남기는 칼선은 벤 직선 그대로.
- 화면에 보일 것:
  - 모으는 동안 칼이 빛나고, 닿을 길이가 바닥에 점선으로 보인다.
  - 다 모이면 칼끝이 번쩍인다.
  - 베면 바닥에 금빛 직선이 남고, 다 모은 베기는 화면이 흔들린다.

## 거인의 칼 `greatsword` (검술 궁극기 칸 `TREES.knight[0][3]`, 처형 자리)

**몇 초 동안 칼이 몸집만큼 커진다. 그동안 평타·가르기·내리베기가 넓고 세지는 대신 느려진다.**

- 등급·비용: 궁극기(처형과 같다). 바로 쓴다(조준 없음, `AIM`에서 처형 줄을 뺀다).
- 지속 6초(단계마다 +0.5초), 재사용 대기 20초(단계마다 −1초)(내 판단, 써 보고 조정).
- 커진 동안(내 판단, 써 보고 조정):
  - **평타**: 대상 하나가 아니라 바라보는 쪽 반원 2.5m 안의 적을 모두 벤다. 피해 ×1.5, 휘두르는 간격 ×1.4.
  - **가르기**(사슬 가르기의 마지막 베기 포함): 범위 ×1.8, 피해 ×1.5.
  - **내리베기**: 길이 ×1.5, 피해 ×1.5.
  - 맞은 적은 1.5m 밀려난다. 무거운 적은 밀리지 않고 휘청인다(내리베기와 같은 규칙: 0.5초, 2초에 한 번).
- 5단계: 끝날 때 거대한 칼로 한 바퀴 크게 벤다(반경 3.5m, 배율 3).
- 다른 스킬과의 연결:
  - 시체 폭발: 커진 동안 평타로 죽인 적도 터진다.
  - 거인의 칼 자체는 베는 스킬이 아니다. 그래서 칼의 여운 칸을 채우지 않는다.
- 화면에 보일 것:
  - 칼이 커지는 모습과 금빛 빛무리.
  - 큰 휘두르기 자국, 무거운 적의 휘청임, 화면 흔들림.

## 지우는 것

- 회오리: `whirl`, `spin`, `spinT`·`spinAcc`, `WHIRL`, `whirlStat`.
  - 회오리 중 평타 대신 돌기(`world.ts`).
  - 렌더에서 회오리 방향을 돌리던 것.
- 처형: `execute`, `EXECUTE`, `executeStat`.
  - 칼의 여운 X자 칼선(`ECHO.x`).
  - 처형의 공포. 공포의 다른 출처는 그대로 둔다.

## 저장 파일 옮기기

`decodeSave`가 읽기 전에 스킬 이름을 바꾼다: `whirl` → `downcut`, `execute` → `greatsword`. 바꿀 곳은 다음과 같다.

- `ranks`의 키
- `keys`의 값
- 룬 주머니(`runes`)의 키: `whirl+2` → `downcut+2`
- 장비 옵션의 룬(`mods`, 가방·창고 장비의 affix `r`)

새 스킬의 등급은 옛 스킬과 같아서 포인트는 그대로 둔다. 옛 세이브가 그대로 읽히는지 `save.test.ts`에 테스트를 하나 넣는다.

## 같이 고칠 곳

- `rules.ts`: `SkillId`, `TREES`, 새 수치 `DOWNCUT`·`GIANT`.
- `core.ts`: `downcutStat`·`greatswordStat`, 평타·가르기 계산에 거인의 칼 반영.
- `abilities.ts`: 내리베기 시작·베기, 거인의 칼.
- `world.ts`: 명령 표, 모으기 틱, 이동 속도.
- `input.ts`·`main.ts`: 키를 떼면 같은 명령을 한 번 더 보낸다(모으는 중일 때만). 터치는 버튼 탭이 이미 명령을 보내므로 그대로 둔다.
- `hud.ts`: 이름·설명·수치 줄, 아이콘. 시체 폭발과 칼의 여운 설명에서 "회오리·처형"을 "내리베기"로 바꾼다.
- 봇(`bot.ts`): `whirl` 빌드를 `downcut` 빌드로 바꾼다. 적이 앞 직선에 둘 이상 있거나 보스가 예고하면 모으기 시작하고, 다 모이거나 보스가 예고 중이면 뗀다.
- 렌더·소리:
  - 모으기 자세와 빛, 직선 베기 효과, 커진 칼.
  - 소리는 가르기 소리를 낮고 무겁게 쓴다.
- 테스트:
  - 회오리·처형 테스트를 내리베기·거인의 칼 테스트로 바꾼다(`tree`, `temper`, `iaido`, `legend`, `runes` 등).
  - 새 테스트:
    - 모은 정도에 따라 길이·피해가 커진다.
    - 맞아도 끊기지 않는다.
    - 키를 다시 누르면 벤다.
    - 거인의 칼 동안 평타가 여럿을 벤다.
    - 무거운 적이 휘청인다.
    - 옛 세이브를 옮긴다.

## 만드는 사람에게 맡기는 것

- 위에서 "내 판단"이라고 적은 수치는 써 보고 조정한다.
- 커진 칼을 그리는 방식: 주인공 스프라이트의 칼을 키울지, 칼 그림을 따로 겹칠지.
- 휘청임은 기존 `stunT`를 쓴다.
