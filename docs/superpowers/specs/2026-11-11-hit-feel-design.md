# 24단계: 타격감 설계

- 날짜: 2026-11-11
- 목표: "스킬이 손맛도 없고 효과도 밋밋하다"를 푼다. 시험판(가르기 하나에 멈춤·흔들림·밀려남·번쩍임·숫자)을 해 보고 "훨씬 낫다"는 확인을 받았다. 이를 스킬 4개 전부에 제대로 넣는다.
- 하지 않는 것: 난이도 조정(다음 단계에서 따로), 새 스킬·새 효과 그림·새 효과음.
- 실패로 보는 것: 평타와 스킬이 똑같이 느껴지는 것, 멈춤 때문에 조작이 씹히는 것, sim의 재현성(같은 시드 = 같은 결과)이 깨지는 것.

## 1. sim: 밀어내기 (`src/sim/core.ts`, `abilities.ts`, `rules.ts`)

`knock(w, e, dx, dz, d)`: 단위 방향 (dx, dz)로 d만큼 0.1m씩 옮기고 벽 앞에서 멈춘다. 살아 있으면 하던 휘두르기·이동이 끊긴다(다음 틱에 다시 쫓아온다). 보스·해골 왕은 밀리지도 끊기지도 않는다. 죽은 적도 밀린다(시체가 날아간다). 부를 때마다 `World.impacts`(스킬이 적을 맞힌 누적 횟수, 렌더용)가 1 오른다.

| 스킬 | 방향 | 거리(`KNOCK`) |
|---|---|---|
| 가르기 | 주인공 반대쪽 | 0.9m |
| 돌진 베기 | 돌진 길의 옆(적이 있는 쪽) | 0.7m |
| 도끼 던지기 | 도끼가 날아온 방향 | 0.6m |
| 전투의 함성 | 주인공 반대쪽(기절은 그대로) | 0.4m |

평타는 밀지 않는다. 난수를 쓰지 않으므로 난수열은 그대로다.

밀려나면 적의 공격이 끊기므로 게임이 조금 쉬워진다. 봇 테스트(`playthrough.test.ts`) 기준을 벗어나면 `MONSTER_DMG`로 되돌린다. 본격적인 난이도는 다음 단계.

## 2. 화면 (`src/render/feel.ts` 새 파일, `render.ts`, `sprites.ts`, `main.ts`)

sim은 건드리지 않고 프레임 사이 변화만 본다(효과음과 같은 방식).

- **멈춤**: `impacts`가 n 늘어난 프레임에 `min(0.14, 0.06 + 0.025n)`초. 그동안 main이 sim 틱을 돌리지 않는다(명령은 큐에 남아 멈춤이 끝나면 실행 → 조작이 씹히지 않는다).
- **흔들림**: 같은 프레임에 `min(0.45, 0.18 + 0.08n)`m, 지수 감쇠. 함성은 맞은 적이 없어도 0.3m. `prefers-reduced-motion`이면 흔들지 않는다.
- **번쩍임**: 체력이 줄어든 몬스터를 스킬 0.09초·평타 0.05초 하얗게. 멈춤 동안은 시간이 가지 않는다.
- **미끄러짐**: sim의 순간 이동(밀려남)을 판자가 약 0.15초에 걸쳐 따라간다. 멈춤이 풀리면서 날아간다.
- **숫자**: 몬스터가 잃은 체력. 스킬 = 크고 노랑, 평타 = 작고 흰색. 주인공이 맞으면 작고 빨강. 위로 떠오르며 사라진다(HTML, Web Animations).

스킬 숫자 판정은 "이번 프레임에 `impacts`가 올랐는가"다. 같은 프레임에 평타가 겹치면 그 평타도 큰 숫자가 되지만 드물고 해가 없다.
