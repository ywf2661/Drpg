# 22단계: 스킬 성장 설계

- 날짜: 2026-10-16
- 목표: 레벨업 때 스킬을 골라 키우는 선택을 만든다.
- 결정 사항(추천안 채택): 레벨업마다 포인트 1, 스킬 4개 모두 1단계에서 시작해 최대 5단계, 포인트는 언제든 찍을 수 있음(되돌리기 없음).

## 1. 단계별 효과 (x = 단계 − 1, 0~4)

| 스킬 | 효과 | 1단계 → 5단계 |
|---|---|---|
| 가르기 | 배율 1.5 + 0.2x, 범위 2 + 0.2x, 재사용 4 − 0.3x | 150% → 230%, 2m → 2.8m, 4초 → 2.8초 |
| 돌진 베기 | 배율 1 + 0.2x, 거리 5 + 0.5x, 재사용 6 − 0.5x | 100% → 180%, 5m → 7m, 6초 → 4초 |
| 전투의 함성 | 기절 2 + 0.3x, 감소 0.3 + 0.04x, 범위 4 + 0.3x, 재사용 15 − x | 2초 → 3.2초, 30% → 46%, 4m → 5.2m, 15초 → 11초 |
| 도끼 던지기 | 배율 1.2 + 0.25x, 재사용 2.5 − 0.2x | 120% → 220%, 2.5초 → 1.7초 |

## 2. 상태·규칙

- `World.ranks = { cleave, dash, shout, throw }`(1~5), `World.points`. 레벨이 오를 때마다 오른 만큼 포인트.
- 명령 `{ type: 'learn'; skill }`: 포인트가 있고 5단계 미만이면 단계 +1, 포인트 −1. 죽어 있어도 가능(창은 언제든).
- 층 사이·저장·회차에 유지(이전 저장은 모두 1단계·포인트 0, 이상한 값이면 저장 무시).

## 3. 화면

- 위쪽 "스킬" 버튼(포인트가 있으면 "스킬 +N", 금색) 또는 `K` 키 → 스킬 창: 스킬마다 이름·단계·다음 단계 효과·[+].
- 하단 스킬 버튼 툴팁·재사용 대기 표시는 지금 단계 수치.

## 4. 완료 기준

1. `npm test`: 레벨업 포인트, 찍기(상한·포인트 없음), 단계별 효과(가르기 배율·범위, 돌진 거리, 함성 기절·재사용, 도끼 배율·재사용), 저장, 봇 테스트(봇은 포인트를 돌아가며 찍음).
2. `npm run build`.
3. 헤드리스: 레벨업 후 버튼 표시, 창에서 찍기, 단계 효과 반영, 콘솔 오류 없음.
