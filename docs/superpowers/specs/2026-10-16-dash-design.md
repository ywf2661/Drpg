# 17단계: 두 번째 스킬 — 돌진 베기 설계

- 날짜: 2026-10-16
- 목표: 물러나는 마법사·멀리 있는 궁수를 따라잡고, 포위에서 빠져나오는 이동기.
- 결정 사항(추천안 채택): 예고 없는 즉시 돌진, 길 위의 적 모두 100%, 재사용 6초. 보스 돌진과 같은 이동 코드를 쓴다.

## 1. 규칙

- 명령 `{ type: 'dash'; x?: number; z?: number }`: (x, z) 방향(없으면 6m 안 가장 가까운 적, 그것도 없으면 바라보는 방향).
- 조건: 살아 있음, `w.dashCd ≤ 0`. 사용하면 `dashCd = 6`, 이동·대상·휘두르기·상자·계단 의도를 끊는다.
- 이동: 14m/s, 최대 5m, 다음 위치가 막힌 칸이면 멈춤. 매 틱 주인공 중심 1m 안의 살아 있는 적 중 이번 돌진에서 아직 안 맞은 적에게 굴림 × 1.0.
- 돌진 중에는 다른 명령(물약 제외)을 무시, 끝나면 대기.
- 보스 돌진과 공용: 엔티티의 `phase: 'charge'`, `phaseT`(남은 거리), `(dx, dz)`.

## 2. 입력·화면

- PC: `F` / `3` — 커서가 가리키는 바닥 방향. 모바일: 스킬 버튼(자동 방향). 버튼에 재사용 대기 표시. 아이콘: FLARE 아이콘(돌진 계열).
- 소리: `melee_attack_3`(돌진 시작). 돌진 중 주인공은 달리기 동작.

## 3. 완료 기준

1. `npm test`: 조준 방향으로 최대 5m 이동, 벽에서 멈춤, 길 위 적만 한 번씩 피해, 재사용 대기, 사망 시 불가, 대상 없이도 사용, 소리 이벤트, 봇 테스트.
2. `npm run build`.
3. 헤드리스: 돌진 이동·피해·버튼 대기 표시, 콘솔 오류 없음.
