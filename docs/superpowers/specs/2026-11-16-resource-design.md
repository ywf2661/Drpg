# 기력·마나 설계

- 날짜: 2026-11-16
- 목적: 롤처럼 스킬을 쓰면 줄고 시간이 지나면 천천히 차는 자원. 기사·궁수는 기력, 마법사·강령술사는 마나. 직업마다 자원 성격이 달라 스킬을 쓰는 리듬이 달라진다.
- 비목표: 전투를 더 어렵게 만드는 것 자체(봇 밸런스 기준을 다시 맞춘다), 마나를 독창적 시스템으로 키우는 것(사용자가 단순한 롤식으로 정했다).

## 규칙

- 재사용 대기는 그대로 두고 비용이 더해진다(롤 방식). 스킬은 재사용 대기가 끝났고 자원이 비용 이상일 때만 나간다.
- 비용은 스킬이 실제로 나갔을 때만 낸다(대상이 없어 안 나가면 내지 않는다).
- 평타(검·마력탄·화살·뼈 화살)와 구르기·순간이동은 무료. 위험할 때 피하는 것은 막지 않는다.
- 층에 들어갈 때·레벨이 오를 때 가득 찬다. 저장하지 않는다(층 시작 때 가득이라 필요 없음).
- 비용은 스킬마다(`SkillId`) 고정, 스킬 단계와 무관. 패시브는 비용 없음.
- 스킬 트리(옆 세션 작업: 직업당 `SkillId` 12개, `TREES[cls]` = 탭 3개 × [1단계, 2단계, 패시브, 궁극], 칸 4개에 끼워 씀) 위에 얹는다. 비용이 칸이 아니라 스킬에 붙어야 칸을 바꿔 끼워도 따라간다.

| | 기력 (기사·궁수) | 마나 (마법사·강령술사) |
|---|---|---|
| 최대치 | 100 고정 | 100 + 레벨마다 +8 |
| 회복 | 초당 10 (10초면 가득) | 초당 4 + 레벨마다 +0.2 |
| 비용 | 작음(1단계 16 · 2단계 24 · 궁극 36) | 큼(20 · 32 · 56) |
| 느낌 | 짧게 몰아 쓰고 숨 고르기 | 큰 주문을 아껴 쓰기 |

비용 시작값은 트리 등급(`SKILLS[id].tier`)으로 정하고(봇으로 조정), 특별히 싸거나 비싸야 할 스킬만 `COST_OVERRIDE`로 덮어쓴다:

| 트리 위치 | 기력 | 마나 |
|---|---|---|
| 1단계 | 16 | 20 |
| 2단계 | 24 | 32 |
| 궁극 | 36 | 56 |
| 패시브 | 0 | 0 |

## 보이는 것

- 체력 막대 아래 자원 막대: 기력 초록, 마나 파랑. 숫자는 막대 위에 작게.
- 자원이 모자란 스킬 버튼은 푸르게 어두워진다(재사용 대기 그늘과 구분). 누르면 "기력이 부족하다" / "마나가 부족하다" 알림.
- 스킬 설명(버튼 툴팁·스킬 트리 창)에 비용.
- 도움말·README에 기력·마나 줄.

## 접근

- 고른 것: 자원 하나(`w.res`)와 직업별 종류(기력·마나)를 표로. 비용 검사·차감은 스킬 트리의 디스패처(`cast()`) 한 곳에서: `id = w.keys[key]`를 구한 뒤 `canAfford(w, id)` 아니면 return, `CASTS[id]`가 돌려준 재사용 대기 `cd > 0`(= 나갔다)이면 `pay(w, id)`. 스킬 함수는 고치지 않는다.
- 고른 것: 비용 = 트리 위치 기본값 + 스킬별 덮어쓰기. 스킬 목록(48개)이 바뀌어도 표를 다시 쓰지 않는다.
- 버린 것: 재사용 대기를 없애고 자원만(디아블로식) — 스킬 수치 전부를 다시 짜야 하고 봇 밸런스가 크게 흔들린다.
- 버린 것: 스킬 함수마다 비용 검사 — 48곳 반복, 빠뜨리기 쉽다.
- 버린 것: 칸(Q W E R)마다 비용 — 칸을 바꿔 끼우면 비용이 따라가지 않는다.
- 미룬 것: 마나 물약, 자원 장비 옵션, 자원을 돌려주는 특성·5단계 효과, 받아치기로 기력 회복.

## 빌더에게 맡긴 것

- 스킬이 재사용 대기 0을 돌려주는 동작(안 나감, 또는 박힌 도끼로 순간이동처럼 대기를 걸지 않는 동작)은 무료.
- 봇: `ready(k)` = `w.keys[k] && w[KEY_CD[k]] <= 0 && canAfford(w, w.keys[k])`. 밸런스 기준(`playthrough.test.ts`)은 다시 재서 갱신하고 주석에 새 수치.
- 모바일 끌어서 조준: 자원이 모자라면 조준을 시작하지 않는다(`canDrag`).
