# 타락한 성기사 — 최종 보스 후보 몬스터

- 날짜: 2026-11-18
- 계기: 사용자 "인간형 두손검사가 Flare 에셋에 있나?" → Flare 대검은 한 손 베기뿐 → 무료 CC0 「8 Directional Greatsword Knight」(Hormelz)를 받음 → "타락한 성기사 느낌으로 칠하고, 몬스터로 만들고, 은은한 후광". 나중에 최종 보스로 쓸 예정.
- 상태: 구현됨(사용자 눈 확인 대기). 계획 밖으로 더한 것: 장면마다 머리 자리표(`fallen_paladin_heads.json`, 금 고리가 머리를 따라감), 소환 제한 `canSummonKnight`(계단·출구·원래 보스가 없는 구역에선 기사가 클리어를 좌우하므로 막음)

## 목표

- 양손으로 대검을 쥐고 내려베는 인간형 보스가 게임 안에서 싸울 수 있는 몬스터로 존재한다.
- 검붉은 판금·흑금·지옥불 칼(배색 C) + 몸 뒤 검붉은 빛무리와 머리 뒤 흐린 금 간 고리(후광 C)로 "타락한 성기사"가 한눈에 읽힌다.
- 이야기에 넣기 전에도 `?test`에서 불러내 보고 싸워 볼 수 있다.

## 하지 않는 것

- 이야기·지역 배치(최종 보스 자리는 아직 없다. 폐허 다음 단계는 따로).
- 고유 패턴(보스 원형 그대로). 밸런스 조정(최종 보스로 넣을 때).
- 유료판 동작(공격 8종·쓰러짐 4종). 무료판 대기·걷기·베기만 쓴다.

## 실패로 보는 것

- 후광이 번쩍여 "은은하게"가 아닌 것, 또는 어두운 바닥에서 아예 안 보이는 것.
- 지어낸 피격·쓰러짐이 어색하게 튀는 것(예: 눕다가 바닥 아래로 꺼짐, 방향마다 다른 쪽으로 넘어짐이 부자연스러움).
- 소환한 기사가 지역 기믹·클리어 판정을 잘못 건드리는 것(아래 "주의").

## 고른 방식

| 방식 | 내용 | 결과 |
|---|---|---|
| **1. 동작은 시트에서, 후광은 렌더러에서** | `sprites.py`가 배색·방향·피격·쓰러짐까지 만든 시트 → 게임은 다른 몬스터와 똑같이 읽음. 후광은 그림 뒤에 붙인 빛 판 | **고름**(사용자) |
| 2. 피격·쓰러짐을 렌더러에서 | 그림 판 기울이기 | 버림 — 이 몬스터만의 예외 코드, 시체 그리기 순서와 꼬임 |
| 3. 후광을 시트에 구움 | | 버림 — 알파 자르기에 반투명 빛이 잘리고 맥동 불가 |

## 설계

**원본** (`tools/.cache/local/greatsword_knight/`, 사용자가 받은 zip 세 개를 푼 것. 자동으로 못 받는다 — 악마와 같은 처지)
- `2hIdle5`(26장), `2hWalk`(9장), `Slash`(12장) × `dir1..8`. 512px 칸, PixelOver JSON(`frames[i].frame`, `duration`).
- 방향: dir1 = 화면 왼쪽 아래, 시계 방향으로 dir8 = 정면(아래). 게임 방향 번호(화면 기준 0=W 1=NW 2=N 3=NE 4=E 5=SE 6=S 7=SW) k → `dir((k+1)%8+1)`.
- 32색뿐. 배색 C(아래)를 색 대 색으로 바꿔 끼운다.

**배색 C** (부위 → 어두운 쪽부터 밝은 쪽 기준점, 원본 색은 부위 안 밝기 순서로 보간)

| 부위(원본 색) | 기준점 |
|---|---|
| 판금(파랑 10색) | (28,10,12) (62,22,24) (108,44,40) |
| 가슴·등판(밝은 청록 5색) | (40,14,16) (90,32,30) (152,64,50) |
| 그늘(짙은 남색 3색) | (8,2,4) (20,6,8) |
| 투구 꼭대기(노랑 4색) | (36,30,20) (90,76,46) (140,120,70) |
| 눈구멍·칼자루(빨강 4색) | (120,40,0) (255,140,20) (255,220,120) |
| 얼굴 조각(올리브 2색) | (60,40,36) (100,70,60) |
| 칼날(흰·회색 3색) | (30,20,20) (255,110,10) (255,230,140) |

시험 코드: 세션 임시 폴더의 `recolor.py`(구현 때 `sprites.py`로 옮긴다).

**시트** `src/assets/sprites/fallen_paladin.{png,json}` — 다른 몬스터 시트와 같은 형식(stance·move·attack·hit·die × 8방향)
- stance = 대기 26장 중 고르게 솎아(시트 4096px 이하, 짓는 사람 몫), 반복.
- move = 걷기 9장, 반복. attack = 베기 12장, 한 번(게임이 휘두르기 진행도에 맞춰 넘긴다 → 보스 간격 1.8초에 늘어난다).
- hit(지어냄, 2장) = 대기 첫 장을 발 기준으로 몇 도 뒤로 젖히고 밝게.
- die(지어냄, 6장 안팎, 한 번, 마지막 장에 멈춤) = 대기 첫 장을 발을 축으로 눕히며(화면에서 바라보는 방향의 반대쪽으로) 어둡게. 마지막 장은 바닥에 누운 모습.
- 배율: 주인공보다 한 덩치 크게(시안 기준 0.5 안팎, `KIND_SCALE`), 알파 자르기·발 기준점은 기존 규칙대로.
- `CREDITS.txt`에 출처(Hormelz, CC0, URL)와 가공 내용 추가.

**게임**
- `Skin`에 `fallen_paladin`: 이름 「타락한 성기사」, 체력 ×1.2, 속도 ×1(악마와 같음). 전투는 `boss` 원형(내려베기·돌진) 그대로. 어느 지역 `skins`에도 넣지 않는다.
- 후광(렌더러, `skin === 'fallen_paladin'`일 때): 그림 뒤에 빛 판 두 장, 가산 혼합, 불빛을 받지 않음.
  - 몸 뒤 검붉은 빛무리(시안보다 옅게), 숨 쉬듯 천천히(약 2~3초 주기) 밝기 오르내림.
  - 머리 뒤 흐린 금 간 고리(호 두 개), 빛무리보다 약하게.
  - 죽으면 서서히 꺼진다. 정확한 크기·밝기·주기는 화면 보며 맞춘다.
- `?test`에 "기사 소환" 버튼: 주인공 근처에 `spawnNear(w, 'boss', …, 'fallen_paladin')`. 야영지에서는 하지 않는다.

**주의(짓는 사람이 확인)**
- 폐허 기믹: 체력 절반 보스를 찾아 무덤을 일으키는 코드가 `kind === 'boss'`만 본다 → 소환한 기사가 악마 대신 걸리지 않게 악마(`skin === 'demon'`)로 좁힌다.
- 클리어 판정: 보스 층에서는 첫 번째 보스(원래 보스)가 판정한다. 소환 기사가 판정·보스 체력바·보스 처치 보상을 엉뚱하게 바꾸지 않는지 확인. 보스 체력바 이름이 지역 보스 이름으로 나와도 시험용이라 괜찮다.

## 짓는 사람 몫

- 대기 솎는 장수, 피격 젖힘 각도, 쓰러짐 장수·각도·어두워지는 정도.
- 후광 판 크기·위치(머리 높이는 시트 기준점에서), 맥동 주기·폭.
- 테스트: 시트 정의(방향 8·동작 5)와 스킨 등록은 기존 시트·스킨 테스트 방식대로, 후광·소환은 헤드리스 화면 확인.
