# 야영지 의뢰·느낌표 설계 (2026-11-18)

## 왜
- 야영지에 들어오자마자 순찰대장 대화창이 뜬다(새 게임 OPENING, 보스 처치 뒤 done). 흐름이 끊긴다.
- 지역 의뢰(흔적·봉화·궤·봉인)가 맡기는 사람 없이 늘 켜져 있다. 주민은 잡담뿐.
- 할 말이 있는 NPC를 멀리서도 알아보게 머리 위 `!`.

## 접근
- **A(채택)**: 이미 있는 지역 의뢰를 주민이 맡기게 한다. 의뢰 4종·이야기 조각을 그대로 쓴다.
- B(버림): 처치·수집형 새 서브퀘스트. 추적·보상·저장을 새로 만들어야 하고 지역 의뢰와 겹친다.

## 사용자가 정한 것
- A로 간다.
- 부탁을 받아야 시작하는 의뢰와 그냥 시작하는 의뢰를 섞는다.
- 보상이 꼭 보스 약화일 필요는 없다.
- 야영지 NPC 사이를 더 띄운다.

## 설계
### 1. 순찰대장: 바로 말 걸지 않기 + `!`
- 야영지에 들어올 때 대화창을 띄우지 않는다. 대신 `news = true`.
- `news`면 이름표가 `! 순찰대장`. 누르면 할 말(새 게임 첫 단계면 OPENING, 아니면 지난 단계의 done)을 하고 `news = false`. 그 뒤로는 지금처럼 `again`.
- 할 말은 (stage, cycle)에서 다시 구한다 → 저장은 `news: boolean` 하나.

### 2. 의뢰인 주민 + `!`
- 야영지 주민 하나를 의뢰인(chest kind `asker`)으로. 다른 하나는 잡담 그대로.
- Quest에 선택 항목 `ask`(의뢰인의 부탁 대사). 있으면 부탁을 들어야 시작 — 저장 `took: boolean`.
  - 시작 전: 의뢰 대상을 맵에 놓지 않고, HUD 임무 줄에 의뢰 진행이 없다. 의뢰인 위 `! 주민`.
  - 누르면 부탁 대사 → 바로 수락(`took = true`), 저장.
  - 수락 뒤 다시 누르면 진행(`실종된 정찰병 1/3 …`), 셋 다 끝내면 잡담.
- `ask`가 없는 의뢰는 지금처럼 처음부터 켜져 있다(대상을 가다가 찾는다). 의뢰인은 잡담.
- 단계가 넘어가면 `took = false`.

### 3. 보상 (Quest.reward)
| 지역 | 의뢰 | 시작 | 조각마다 | 셋 다 |
|---|---|---|---|---|
| 초원 | 실종된 정찰병 | 부탁 | 금화 10×깊이 | 스킬 포인트 +1 |
| 설원 | 꺼진 봉화 | 부탁 | 금화 10×깊이 | 스킬 포인트 +1 |
| 미궁 | 열쇠지기 | 처음부터 | 보스 체력 −10% | 스킬 포인트 +1, 전설 확정 |
| 폐허 | 봉인 제단 | 처음부터 | 보스 체력 −10% | 스킬 포인트 +1, 전설 확정 |

미궁·폐허는 이야기 조각이 이미 보스를 약하게 만드는 내용이라 보스 약화를 유지한다(내 판단).

### 4. 느낌표 표시
- `Sign`에 `alert?: boolean` → `label sign alert` 클래스, CSS `::before`로 노란 `!`.

### 5. 야영지 배치
- 순찰대장·상인·의뢰인·주민을 모닥불에서 4~5칸 거리로 띄운다(지금은 2~3칸). 큰 소품(o)은 겹치지 않게 옮긴다.

### 6. 저장·호환
- `news`·`took` 추가. 옛 저장: `news = false`, `took = marks > 0`.

### 7. 테스트
- 봇(밸런스)은 의뢰 보상을 받지 않으므로 그대로.
- 규칙 함수(할 말, 의뢰가 켜졌는지, 조각 보상)와 저장 호환에 테스트 하나씩.
