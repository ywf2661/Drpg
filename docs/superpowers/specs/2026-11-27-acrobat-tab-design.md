# 궁수 곡예 탭: 갈고리 화살 · 공중제비 사격 · 기세 · 숨 멈춤

- 날짜: 2026-11-27
- 계기: 사용자 "궁수는 사격·화살비·불화살비만 쓰면 적이 녹아서 끝이다. 마법사 잔상처럼 스타일리시한 플레이를 궁수 특성으로 달라"
- 상태: 설계(사용자가 방향을 골랐다. 구현은 아직 안 함, 토큰 한도 때문에 문서만)
- 그림: 숨 멈춤이 걸리고 풀리는 장면(https://claude.ai/artifact/THo8y8A5BDEM17WiuAesTU)

## 왜 바꾸나

- 사냥 탭(덫·밀쳐내기 사격·덫 숙련·사냥터)은 넷 다 깔아 두고 기다리는 스킬이다. 화살비보다 손이 더 가는데 보상이 없어서 안 쓴다.
- 마법사 잔상이 멋있는 까닭은 **어디에 서 있느냐가 피해를 바꾸기** 때문이다. 궁수는 이걸 **몸놀림**으로 한다.

## 목표 / 하지 않는 것 / 실패로 보는 것

- 목표: 사냥 탭을 곡예 탭으로 통째로 바꾼다. "날아다니며 쏘면, 가만히 서서 쏠 때보다 확실히 세다"가 되어야 한다.
- 하지 않는 것:
  - 갈고리로 벽을 **넘어가지 않는다**. 붙는 데서 끝난다(사용자). 맵 동선을 지킨다.
  - 회수(꽂힌 화살 되돌리기)는 넣지 않는다(사용자: "회수는 별로").
  - 사격·하늘·매 탭은 건드리지 않는다. 화살비 수치 조정은 새 탭을 다 넣은 뒤 따로 본다.
- 실패로 보는 것:
  - 덫·사냥터를 배운 기존 저장 파일을 못 읽는다.
  - 숨 멈춤 동안 주인공까지 느려진다.
  - 숨 멈춤이 풀릴 때 멈춰 있던 스킬이 사라지거나 두 번 터진다.
  - 갈고리로 벽 안쪽이나 맵 밖에 끼인다.

## 고른 방식(대화에서)

| 결정 | 고른 것 | 버린 것 |
|---|---|---|
| 탭 방향 | **곡예**: 몸놀림이 피해가 된다 (사용자) | 꽂힌 화살·회수, 데드아이(찍어 두고 한꺼번에 쏘기) |
| 1번 칸 | **갈고리 화살**: 진격의 거인 입체기동처럼 쏜 곳으로 끌려간다 (사용자) | 덫 |
| 궁극기 | **숨 멈춤**: 나만 빠르고, 쏜 스킬은 느리게 떠 있다가 풀릴 때 팍 나간다 (사용자) | 사냥터 |
| 갈고리 범위 | **벽·기둥에 붙는 데서 끝** (사용자) | 벽 넘기 |
| 숨 멈춤 끝내기 | **다시 누르면 바로 풀림, 안 누르면 3초 뒤 저절로** | 시간만 다 쓰기 |

## 저장 파일·코드 이름

새 이름을 쓰고 `src/save.ts`의 이름 바꾸기 줄(`whirl`→`downcut`을 바꾸는 곳)에 같은 방식으로 더한다.

| 옛 스킬 | 새 스킬 | 코드 이름 |
|---|---|---|
| 덫 `trap` | 갈고리 화살 | `grapple` |
| 밀쳐내기 사격 `push` | 공중제비 사격 | `flip` |
| 덫 숙련 `snare` | 기세 | `momentum` |
| 사냥터 `hunt` | 숨 멈춤 | `breath` |

탭 이름 `사냥` → `곡예`. 배운 단계는 그대로 옮긴다.

## 갈고리 화살 `grapple` (곡예 1번 칸)

**겨눈 쪽으로 갈고리를 쏘고, 맞은 것에 따라 내가 끌려가거나 적을 끌어온다.**

- 벽·기둥에 맞으면: 그 앞 한 칸(걸을 수 있는 칸)까지 빠르게 끌려가 멈춘다. 날아가는 동안 맞지 않는다.
- 작은 적(졸개·궁수·마법사)에 맞으면: 적이 내 앞으로 끌려온다.
- 큰 적(전사·정예·보스·거대적)에 맞으면: 내가 그 적 앞까지 날아가 걷어차고, 반대쪽으로 짧게 튕겨 나온다. 적은 잠깐 기절.
- 아무것도 안 맞으면 갈고리만 돌아오고 재사용 대기는 절반만 든다.
- 수치(시작값): 재사용 5초, 사거리 9m, 날아가는 속도 18m/s, 걷어차기 배율 1.2, 기절 1초.
- 5단계: 연달아 두 번 쓸 수 있다(충전 2).
- 다시 쓸 코드: 사슬 가르기의 `hook` 투사체(쏘기·되감기·거대적에 박힘)를 그대로 쓴다. 끌려가는 이동은 구르기(`roll`)의 이동을 쓰고 거리만 바꾼다. 착지 칸은 `walkable`로 고른다.

## 공중제비 사격 `flip` (곡예 2번 칸)

**뒤로 공중제비를 돌며 물러나고, 공중에서 방금 서 있던 자리에 화살을 부채꼴로 내리꽂는다.**

- 바라보는 반대쪽으로 3m 물러난다(벽이면 벽 앞에서 멈춤). 도는 동안 맞지 않는다.
- 떠난 자리 둘레 반경 1.8m에 화살 5발이 꽂힌다. 배율 1.0.
- 붙은 적을 떼어 내면서 바로 반격하는 스킬이다.
- 수치(시작값): 재사용 6초.
- 5단계: 착지하면서 떠난 자리 쪽으로 관통 화살 한 발을 더 쏜다.
- 다시 쓸 코드: 구르기 이동 + 화살비의 낙하(`w.volleys`)를 떠난 자리에 깐다.

## 기세 `momentum` (곡예 패시브)

**갈고리·공중제비·구르기로 착지한 직후에 쏜 것은 반드시 치명타가 되고, 더 빨리 날아간다.**

- 착지 뒤 `0.8 + 0.1 × (단계 − 1)`초 동안 쏜 평타·스킬 화살은 치명타(2배)가 되고, 속도가 1.3배로 빨라진다.
- 치명 패시브(`crit`)와 겹치면 한 번만 친다(2배를 두 번 곱하지 않는다).
- 화면: 착지할 때 발밑에 금색 고리 + "기세" 글자. 기세가 남은 동안 활에 금빛.

## 숨 멈춤 `breath` (곡예 궁극)

**세상이 거의 멈추고 주인공만 제 속도로 움직인다. 그동안 쓴 스킬은 아주 느리게 떠 있다가, 풀리는 순간 한꺼번에 나간다.**

- 지속 3초(5단계 3.5초). 재사용 18초.
- 멈춘 동안:
  - 적·적 투사체·주인공이 쏜 화살·화살비·매는 시간이 0.04배로 흐른다.
  - 주인공의 이동·구르기·갈고리·스킬 쓰기는 제 속도다.
  - **갈고리 화살은 재사용 대기 없이** 쓸 수 있다. 기둥을 옮겨 다니며 사방에서 걸어 두는 게 이 궁극기의 핵심이다.
  - 주인공 화살은 갈 길을 점선으로 미리 보여 준다.
  - 화살비는 하늘에 멈춰 있고, 땅에 그림자만 보인다.
- 끝내기:
  - 다시 누르면 바로 풀린다. **일찍 풀면 남은 시간만큼 숨 멈춤 재사용 대기가 줄어든다.**
  - 안 누르면 시간이 다 되어 저절로 풀린다.
  - 풀리면 시간이 1배로 돌아오고 화면이 하얗게 번쩍인다. 따로 터뜨리는 건 없고 걸어 둔 것들이 제 속도로 날아갈 뿐이다.
- 화면: 푸른 막 + 가장자리 그늘, 위쪽 가운데 남은 시간 게이지, 주인공만 초록 잔상 꼬리.

### 구현 방향

- `World`에 `slowT`(남은 시간)와 `slow`(지금 배율, 평소 1)를 둔다.
- `tick`에서 주인공 말고 움직이는 것들(적 AI·`w.shots`·`w.volleys`·`w.storm`·매·불길 등)에 넘기는 dt에 `w.slow`를 곱한다. 주인공 이동·쿨다운·입력은 원래 dt.
- 숨 멈춤 동안 갈고리 쿨다운을 0으로 둔다.
- 모든 tick 함수를 하나씩 손대는 게 핵심 작업이라 가장 크다. 빠지는 게 없는지 "주인공 것만 1배" 목록을 테스트로 잡는다.

## 봇·HUD·설명

- `bot.ts`: 궁수 봇이 덫·사냥터를 쓰던 자리를 갈고리(적이 붙으면 뒤 벽으로)·공중제비(가까이 붙었을 때)·숨 멈춤(보스전)으로 바꾼다.
- `hud.ts`·`render/props.ts`: 덫 그리기를 지우고 갈고리 줄·기세 고리·숨 멈춤 막을 그린다.
- 스킬 설명은 자연스러운 한국어로, 실제 동작 그대로 쓴다.

## 테스트

- 저장: 덫·사냥터를 배운 저장 파일을 읽으면 갈고리·숨 멈춤으로 단계가 옮겨진다.
- 갈고리: 벽에 쏘면 벽 앞 걸을 수 있는 칸에 선다 / 졸개는 끌려온다 / 보스는 기절하고 내가 튕겨 나온다.
- 공중제비: 뒤로 물러나고 떠난 자리에 화살이 떨어진다. 벽 앞에서는 멈춘다.
- 기세: 착지 직후 화살은 치명타, 시간이 지나면 아니다.
- 숨 멈춤: 동안 적은 거의 안 움직이고 주인공은 제 속도 / 쏜 화살은 풀린 뒤에 맞는다 / 다시 누르면 바로 풀리고 남은 시간만큼 대기가 준다 / 갈고리 대기 없음.
- 봇 5층 기준 궁수 판수가 크게 나빠지지 않는다.
