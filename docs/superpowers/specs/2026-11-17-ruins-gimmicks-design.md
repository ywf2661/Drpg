# 새 지역(폐허)과 기존 지역 기믹 설계

- 날짜: 2026-11-17
- 이어서: `2026-11-16-outdoor-design.md`(72칸 바깥 맵, 초원 1구역 갈림길)
- 상태: **기획 — 사용자가 고르면 구현**

## 1. 새 지역 후보

FLARE에 남은 원본 그림으로 만들 수 있는 것만 골랐다(새 타일셋은 `empyrean_campaign/tileset_ruins` 하나뿐 — 나머지 안은 기존 타일 색을 바꿔 쓴다).

| 안 | 맵 | 몬스터(원본 그림) | 기믹 | 그림 품질 |
|---|---|---|---|---|
| **A. 폐허(잊힌 성채)** — 추천 | 72칸. 무너진 돌집 블록 사이로 골목·광장, 이끼 낀 돌바닥과 흙. 반쯤 실내 — 벽 뒤에 숨는 싸움 | 어둠 좀비(졸개), 홉고블린(전사), 홉고블린 궁수(궁수), 보스 해골 기사 왕(`skeleton_knight_boss`) | 저주받은 무덤, 가시 바닥, 푸른 마법진 | 새 타일셋 그대로 — 가장 좋음 |
| B. 화산 협곡 | 동굴 타일을 붉게. 용암 줄기가 맵을 가른다 | 불개미, 갑옷 개미귀신, 보스 불 와이번 | 용암 분출 예고 원, 용암 위 지속 피해 | 색만 바꾼 재활용 |
| C. 늪지 | 초원 타일을 어둡게 | 좀비, 새끼 개미귀신, 보스 개미귀신 | 독 웅덩이(감속·지속 피해) | 색만 바꾼 재활용 |

### A. 폐허 상세

- **들어가는 길**: 초원 1구역 갈림길의 넷째 출구(들어온 쪽을 뺀 세 가장자리가 초원 2·설원 1·폐허 1, 동굴 입구는 지금처럼 맵 안쪽). 고른 뒤로는 폐허 2 → … → 5(보스).
- **맵**: 72×72에 8~12칸 크기의 돌집 블록을 격자로 놓고, 블록 벽을 30~50% 무너뜨린다(틈 = 드나드는 곳). 블록 사이 3칸 골목, 가운데 광장 하나. 가장자리는 높은 성벽. 시야는 초원처럼 낮(디아2식 먼 적 숨김), 단 해 질 녘 색조.
- **싸움의 느낌**: 초원(트임)·설원(흩어짐)·미궁(방) 사이 — 골목에서 궁수에게 쏘이고, 집 안으로 끌고 들어가 끊어 친다.
- **기믹**
  1. **저주받은 무덤**(`cursed_grave` 그림): 구역마다 3~5개. 가까이 가면 8초마다 어둠 좀비가 하나씩 기어 나온다(최대 3마리 살아 있게). 무덤은 체력이 있는 물체 — 부수면 멈추고 금화·물약을 떨어뜨린다. "먼저 무덤을 깰지, 몰려오는 좀비를 칠지".
  2. **가시 바닥**(타일셋의 붉은 쇠살 바닥): 골목 몇 곳에 2×2. 3초 주기로 1초 전 반짝이고 솟는다. 몬스터도 다친다 — 끌어들여 쓸 수 있다. 구르기 무적이면 안 다침.
  3. **푸른 마법진**(타일셋 맨 윗줄): 맵에 한 쌍. 밟으면 짝 마법진으로 순간이동(재사용 5초). 길을 질러가거나 무리에서 빠지는 용.
- **보스 해골 기사 왕**: 돌진 원형 그대로 + 체력 50%마다 무덤 두 개를 일으킨다(위 기믹 재사용).
- **새로 만들 것**: 타일(바닥 8·벽 4, `tools/sprites.py`의 `WILDS`에 한 줄), 몬스터 시트 4장(홉고블린·궁수·어둠 좀비·해골 기사 왕), 무덤·가시·마법진 소품. 코드는 `Land`에 `'ruins'`, `generateWild`에 블록 배치, `exitsFor`·출구 글자 `R`·저장 목록.

## 2. 기존 지역 기믹 후보

각 줄이 하나의 작은 단위(따로 넣고 따로 뺄 수 있다). ★ = 추천.

### 초원

| | 기믹 | 내용 | 일 크기 |
|---|---|---|---|
| ★ | **보물 고블린** | 구역마다 30% 확률로 하나. 주인공을 보면 도망가고(빠름, 안 싸움), 12초 안에 못 잡으면 땅속으로 사라진다. 잡으면 금화 분수 + 장비 1~2개. 고블린 수레(`goblin_minecart`) 그림 | 중 |
| ★ | **개미지옥 모래 구덩이** | 들판에 3×3 모래 구덩이 2~3개(바닥 색 변형). 밟으면 가운데로 천천히 끌려가고 이동 −40%, 가운데에 새끼 개미귀신이 숨어 있다 튀어나온다 | 중 |
| | 굴러오는 바위 | 절벽 가장자리 근처에서 가끔 바위가 일직선으로 굴러온다(1.5초 전 붉은 줄 예고 — 화살비 예고와 같은 방식). 몬스터도 깔린다 | 중 |

### 설원

| | 기믹 | 내용 | 일 크기 |
|---|---|---|---|
| ★ | **얼어붙은 보물** | 얼음 덩어리 속에 갇힌 상자 1~2개. 평타·스킬로 쳐서 깬다(불 스킬은 2배). 깨는 동안 주변 얼음 개미가 깨어난다 | 작음 |
| ★ | **고드름 낙하** | 얼음 절벽 옆을 지나면 가끔 머리 위에 예고 원 → 1초 뒤 고드름(피해 + 짧은 기절). 눈보라 중에는 2배로 잦다 | 작음 |
| | 추위 | 모닥불에서 멀리 오래 있으면 서서히 느려진다(최대 −20%), 모닥불 곁에서 풀린다. 설원에 모닥불이 이미 8개 있다 | 중 — 답답할 수 있음 |

### 미궁

| | 기믹 | 내용 | 일 크기 |
|---|---|---|---|
| ★ | **성소** | 층마다 1~2개 석상(이미 소품에 있음). 클릭하면 30초 버프 하나 — 분노(공격 +50%), 수호(받는 피해 −40%), 신속(이동·공격 +30%), 지혜(경험치 +50%). 바깥 지역에도 같이 넣을 수 있다 | 작음 |
| ★ | **포위 방** | 보물 방 하나가 "포위 방": 들어가면 사슬 문이 닫히고 몬스터가 세 번 몰려온다. 다 막으면 문이 열리고 희귀 장비 확정 | 중 |
| | 다시 일어나는 해골 | 해골 졸개가 쓰러진 뒤 30% 확률로 4초 뒤 일어난다(뼈 더미가 흔들리는 예고). 그 전에 밟거나 치면 끝 | 작음 |

## 3. 추천 순서

1. **성소**(작음, 모든 지역에 쓰임, 바로 재미) → 2. **보물 고블린** → 3. **폐허 지역** → 4. 나머지 ★를 하나씩.
- 기믹 하나 넣을 때마다 `playthrough` 봇으로 사망 수가 크게 안 바뀌는지 확인(성소·보물은 봇이 무시해도 된다 — 보상만 늘어남).

## 4. 아닌 것

- 이동 물리(미끄러운 얼음) — 지난번에 안 해도 된다고 함.
- 지역 보스 고유 패턴 전체 개편 — 폐허 보스의 무덤 소환만.
- 새 소리.
