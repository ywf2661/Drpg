# 14단계: 보스 패턴 — 미노타우르스 돌진 설계

- 날짜: 2026-10-15
- 목표: 보스전에 읽고 피하는 요소를 넣는다. 예고 → 직선 돌진 → 피하면 빈틈.
- 결정 사항(추천안 채택): 돌진 하나만(단계 전환 없음), 예고는 붉게 달아오르는 색, 피하면 피해 없음.

## 1. 규칙 (`src/sim/world.ts`, 보스만)

| 항목 | 값 |
|---|---|
| 조건 | 대상(주인공)과 3~7m, 시야 트임, 재사용 대기 0 |
| 예고(windup) | 0.7초 제자리, 주인공을 바라봄 |
| 돌진(charge) | 예고가 끝난 순간 주인공 위치 방향으로 직선, 9m/s, 최대 7m |
| 멈춤 | 다음 위치가 막힌 칸, 7m 소진, 또는 주인공 0.8m 이내(그때 굴림 × 1.5 피해, 갑옷 적용) |
| 재사용 대기 | 7초(예고 시작 때부터) |

- 엔티티에 `phase: 'none' | 'windup' | 'charge'`, `phaseT`, `cd`, `dir`(돌진 방향 단위 벡터)를 둔다(보스 외엔 늘 none).
- 예고 중 상태는 `idle`(대기 동작), 돌진 중은 `move`.

## 2. 그림·소리

- 예고 중 보스 색을 붉게 맥동(렌더가 `phase`를 읽음).
- 예고 시작에 `boss_attack` 소리(이벤트: phase가 windup이 됨).

## 3. 밸런스

보스 밸런스 테스트(물약 없이 지고, 물약 있으면 이김)와 봇 1~5층 테스트를 다시 맞춘다. 봇은 피하지 않으므로 사람에게는 더 쉽다.

## 4. 완료 기준

1. `npm test`: 예고 후 돌진해 가만히 있는 주인공을 맞힘(150%), 예고 중 옆으로 비키면 빗나감, 벽에서 멈추고 벽 안으로 들어가지 않음, 재사용 대기, 3m 안에서는 돌진하지 않음, 소리 이벤트, 기존 밸런스 테스트.
2. `npm run build`.
3. 헤드리스: 붉은 예고와 돌진 화면, 콘솔 오류 없음.
