# 5-C단계: 앞쪽 벽 낮추기 설계

- 날짜: 2026-10-15
- 목표: 주인공이 카메라 쪽(+x+z) 벽 뒤에 있을 때 가려지지 않게, 주인공을 가리는 근처 벽만 낮춘다(디아블로 2 방식).
- 결정 사항(추천안 채택): 반투명 대신 높이를 0.25m로 낮춘다(도트 질감·깊이 정렬 유지). 몬스터는 대상이 아니다.

## 1. 판정 `occludes(hx, hz, wx, wz)` (순수 함수, `src/render/cutaway.ts`)

벽 칸 중심 (wx + 0.5, wz + 0.5)과 주인공 (hx, hz)의 차이를 카메라 방향 성분 `a = (dx + dz) / √2`(카메라 쪽 +), 화면 가로 성분 `b = (dx − dz) / √2`로 나누어:
- `0 < a ≤ 2.6`(주인공보다 카메라 쪽, 1.2m 벽이 1.7m 캐릭터를 가릴 수 있는 거리), `|b| ≤ 1.3`(화면에서 주인공 폭 근처)이면 가린다.

## 2. 렌더

- 벽 InstancedMesh의 칸 → 인스턴스 번호를 기억하고, 매 프레임 가리는 벽 집합이 바뀌었을 때만 해당 인스턴스 행렬을 낮은 상자(높이 0.25, 바닥에 붙음) ↔ 원래 상자로 바꾼다.
- 낮춘 벽의 윗면은 원래 윗면 재질(어두운 돌)이라 바닥과 구분된다.

## 3. 완료 기준

1. `npm test`: 바로 앞(카메라 쪽) 벽은 가림, 뒤쪽 벽·옆으로 먼 벽·너무 먼 벽은 아님.
2. `npm run build`.
3. 헤드리스: 앞쪽 벽 바로 뒤에 선 주인공이 보인다(전후 스크린샷), 콘솔 오류 없음.
