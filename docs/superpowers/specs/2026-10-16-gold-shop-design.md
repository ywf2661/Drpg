# 16단계: 금화와 층 사이 상점 설계

- 날짜: 2026-10-16
- 목표: 운에만 기대던 성장에 선택을 더한다. 금화를 모아 물약을 살지, 장비를 강화할지 고른다.
- 결정 사항(추천안 채택): 금화는 바닥 더미(밟으면 자동 획득), 상점은 계단을 내려갈 때마다(2~5층 진입 전) 뜨는 화면, 인벤토리 없음.

## 1. 금화 (`src/sim/world.ts`)

| 출처 | 확률 | 양 (× 몬스터 층 배율, 반올림) |
|---|---|---|
| 졸개 | 50% | 3–8 |
| 전사 / 궁수 / 마법사 | 60% | 8–15 / 5–10 / 6–12 |
| 정예 | 100% | 40–60 |
| 상자 | 100%(내용물에 더해) | 15–30 × 층 배율 |

- `Item.kind`에 `'gold'`, `Item.amount`(금화 양, 다른 종류는 0). 줍기 반경은 물약과 같음, 개수 제한 없음.
- `World.gold`. 층 사이 유지·저장(사망 시 그 층 진입 때 금액).

## 2. 상점 (`src/shop.ts`, 순수 함수)

계단을 내려가면 다음 층을 만들기 전에 상점 화면(게임 정지). 항목:

| 항목 | 가격 | 조건 |
|---|---|---|
| 체력 물약 1개 | 25 | 허리띠 8개 미만 |
| 무기 한 단계 강화 | 120 × 현재 단계 | 4단계 미만 |
| 갑옷 한 단계 강화 | 100 × 현재 단계 | 4단계 미만 |

- `offers(c)` → 항목별 가격·살 수 있는지, `buy(c, item)` → 새 상태(못 사면 그대로). 여러 번 살 수 있음. [다음 층으로] 버튼.

## 3. 화면·소리

- HUD 물약 옆에 금화 수. 바닥 금화는 FLARE `loot/coins5`·`coins25`·`coins100`(양에 따라), 이름표에 "금화 N"(금색 아님).
- 금화 줍기: `inventory_coins.ogg`. 구매: 같은 소리.

## 4. 범위 밖

판매, 무작위 상품, 상인 캐릭터, 마을.

## 5. 완료 기준

1. `npm test`: 금화 드롭 확률·양(배율), 정예·상자 확정, 자동 줍기(제한 없음), 저장·복원(이전 저장은 0), 상점 가격·조건·구매, 봇 테스트(봇은 상점에서 물약을 사고 남으면 강화).
2. `npm run build`.
3. 헤드리스: 금화 줍기·HUD, 계단 → 상점 → 구매 → 다음 층, 콘솔 오류 없음.
