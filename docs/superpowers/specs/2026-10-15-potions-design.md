# 3-A단계: 체력 물약 설계

- 날짜: 2026-10-15
- 목표: 몬스터가 체력 물약을 떨어뜨리고, 주워 두었다가 위급할 때 마셔 버티는 디아블로식 자원 관리를 넣는다. 3단계(아이템)의 첫 조각.
- 결정 사항(추천안 채택): 줍기는 자동(지나가면 줍기, 모바일 친화), 즉시 회복, 물약은 층을 내려가도 유지, 화면 버튼 + 키보드 단축키.
- 후속: 3-B 장비(무기·방어구 드롭, 인벤토리, 외형 레이어 합성).

## 1. 규칙 `src/sim/world.ts`

| 항목 | 값 |
|---|---|
| 드롭 | 몬스터가 죽을 때 졸개 20%, 전사 35% 확률(world PRNG)로 물약 1개를 그 자리에 |
| 줍기 | 살아 있는 주인공 중심에서 0.6m 이내 물약을 매 틱 자동으로 줍는다. 허리띠 최대 8개, 가득 차면 바닥에 남는다 |
| 마시기 | 명령 `{ type: 'drink' }`. 물약 ≥ 1, 체력 < 최대, 살아 있음 → 1개 소모, 체력 + 최대의 50%(최대치까지). 이동·공격·계단 의도를 끊지 않는다 |
| 시작 | 1층 시작 시 2개 |

- `World`에 `items: { id: number; x: number; z: number }[]`, `nextItem: number`, `potions: number` 추가. `createWorld`는 `items = []`, `potions = 0`(main이 넣어 준다).
- 드롭 판정은 `damage()`에서 대상이 죽을 때. 같은 시드 + 같은 명령 = 같은 드롭(재현성 유지).

## 2. 진행 `src/main.ts`

- 내려가기: 현재 물약 수를 새 층으로 가져간다.
- 사망 후 다시 시작: 그 층에 들어왔을 때의 물약 수로.
- 클리어 후 다시 시작(1층): 2개.

## 3. 입력·HUD

- 키: `Q` 또는 `1`(e.code `KeyQ`/`Digit1`, 한글 입력 상태에서도 동작).
- 화면 왼쪽 아래 체력바 옆에 물약 버튼(FLARE 아이콘 + 개수). 누르면 마시기. 0개면 흐리게.

## 4. 렌더

- 바닥 물약: FLARE `loot/hp_potion` 떨어지는 애니메이션(6프레임, 600ms, play_once) 후 마지막 프레임. 축소 0.5(작은 그림이라 타일 배율 0.221이면 6px로 보이지 않음). 밝기 = max(불빛, 0.6)로 어둠 속에서도 보이게.
- `tools/sprites.py`가 `src/assets/sprites/loot.{png,json}`(동작 `potion`)과 `src/assets/sprites/potion_icon.png`(아이콘 64번, 64×64)를 만든다. CREDITS에 `images/loot/hp_potion.png`, `animations/loot/hp_potion.txt`, `images/icons/icons.png` 추가, 크레딧 문구 "캐릭터·던전·아이템 그림".
- 물약 판자는 `props.ts`의 판자 방식을 재사용(`card`), 매 프레임 `world.items`와 맞춘다(id로 생성·제거).

## 5. 범위 밖

마나·기타 물약, 클릭 줍기·아이템 이름표, 금화, 상자 열기, 장비(3-B), 효과음.

## 6. 완료 기준

1. `npm test`: 드롭 확률(시드 400개로 졸개 12~28%), 드롭 위치 = 시체 위치, 자동 줍기, 가득 찼을 때 남김, 마시기(회복량·최대치·0개·체력 가득·사망), 마시기가 이동·계단 의도를 끊지 않음, 재현성, loot 시트 계약.
2. `npm run build` 성공.
3. 헤드리스 Chrome: 물약 버튼 표시, 몬스터를 잡아 물약이 떨어지고 주우면 개수 증가, Q로 체력 회복, 층 이동 후 개수 유지, 콘솔 오류 없음.
