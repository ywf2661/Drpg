# 26단계: 스킬 연계·5단계 완성 효과 설계

- 날짜: 2026-11-11
- 목표: 스킬이 "대기가 끝나면 누르는 버튼"인 구조를 바꾼다. 언제·어떤 순서로 쓸지(연계), 무엇부터 올릴지(완성 효과)에 선택이 생기게 한다.
- 하지 않는 것: 새 스킬(5번째 슬롯), 자원(분노), 난이도 수치(25-2).
- 실패로 보는 것: 연계가 터졌는데 화면에서 알 수 없는 것, 기존 1~4단계 수치가 바뀌는 것.

## 1. 연계 (`core.ts`의 `skillHit`, `abilities.ts`)

스킬 피해(가르기·돌진·도끼)는 모두 `skillHit(w, e, raw)`를 거친다.

| 연계 | 조건 | 효과 | 표시 |
|---|---|---|---|
| 받아치기 | 맞는 적이 예고 자세(`phase === 'windup'`: 전사 내려찍기, 보스 돌진 예고, 해골 왕 소환) | 피해 × `COMBO.counter`(2) | "받아치기!" |
| 약점 | 맞는 적이 기절 중(`stunT > 0`) | 피해 × `COMBO.stunned`(1.5) | "약점!" |
| 연속 | 돌진 베기가 적을 맞힘(돌진당 한 번) | 가르기 재사용 대기 0 | "가르기 준비!" |

기록: `World.combos: { id, x, z, kind, age }[]`(폭발 기록처럼 잠시 뒤 지움, 렌더가 글자를 띄운다). 평타에는 연계가 없다.

## 2. 5단계 완성 효과

1~4단계 수치는 그대로, 5단계(`RANK_MAX`)에 하나씩 더한다.

| 스킬 | 효과 |
|---|---|
| 가르기 | 반원 → 한 바퀴(뒤쪽 적도) |
| 돌진 베기 | 돌진으로 적을 처치하면 돌진 대기 0 |
| 전투의 함성 | 쓸 때 최대 체력의 `SHOUT.heal`(15%) 즉시 회복 |
| 도끼 던지기 | 관통: 길 위의 적을 한 번씩 모두 맞히고 끝까지 난다 |

스킬 툴팁에 "5단계: …"를 항상 보여 준다(찍었으면 ✓).
