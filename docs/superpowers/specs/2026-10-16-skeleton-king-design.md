# 19단계: 3층 중간 보스 — 해골 왕 설계

- 날짜: 2026-10-16
- 목표: 5층 보스 전에 기억에 남는 전투 하나. 소환을 끊으려면 왕을 먼저 노려야 한다.
- 결정 사항(추천안 채택): 3층 계단 방에 배치(계단으로 가려면 거의 마주침, 처치는 선택), 전사 그림을 크게·보라색으로, 소환은 졸개 2마리.

## 1. 해골 왕 (`kind: 'king'`, 글자 `K`)

| 항목 | 값 |
|---|---|
| 체력 | 260 × 층 배율 |
| 데미지 / 간격 / 속도 | 9–14 / 1.5초 / 2.2m/s |
| 소환 | 대상이 8m 안이면 8초마다: 0.8초 시전(제자리, 예고 색) → 주변 빈 칸에 졸개 2마리(왕의 배율). 왕이 부른 졸개가 6마리 살아 있으면 쉰다 |
| 경험치 | 150 × 배율 |
| 드롭 | 최고 단계 장비 + 금화 80–120 × 배율 + 물약, 모두 확정 |

- 소환된 졸개는 일반 졸개와 같다(경험치·드롭 포함). `entities`에 뒤로 추가되므로 id = 배열 위치가 유지된다.
- 시전은 보스 돌진과 같은 `phase: 'windup'`을 쓰고, 끝나면 `phase: 'none'`.

## 2. 생성기

- 3층에서 계단 방 안, 계단과 체비셰프 2~3칸 떨어진 빈 칸에 `K`.

## 3. 렌더·소리·HUD

- 전사 시트를 1.5배, 보라 색조. 예고 중 맥동(보스와 같은 방식).
- 게임 중 새 엔티티: 렌더는 판자를 만들고, 소리 비교는 새 엔티티를 건너뛴다.
- 상단 보스 체력바: 해골 왕도 표시(이름 바꿈).
- 소리: 소환 시 `teleport.ogg`.

## 4. 완료 기준

1. `npm test`: 생성기(3층에만 K 1개, 계단 방), 체력·배율, 8초 간격 시전 → 졸개 2마리, 6마리 제한, 드롭 확정, 새 엔티티와 소리 이벤트, 봇 테스트.
2. `npm run build`.
3. 헤드리스: 왕·소환 화면, 보스 체력바 이름, 콘솔 오류 없음.
