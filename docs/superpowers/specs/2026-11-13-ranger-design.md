# 궁수 직업 설계

- 날짜: 2026-11-13
- 목표: 기사(근접)·마법사(범위·제어 원거리)에 이어 세 번째 직업. **단일 대상 저격 + 덫 한 칸**으로 마법사와 겹치지 않는 물리 원거리.
- 결정 사항(추천안 채택): 저격수(A)에 사냥꾼(B)을 한 칸 섞는다. 스킬 Q 관통 사격 · W 덫 · E 화살비 · R 집중, 스페이스는 기사 구르기.

## 왜

직업이 둘뿐이라 다시 시작할 이유가 적다. Flare에 활 4종(새총·단궁·장궁·대궁)과 `shoot` 동작, 화살·덫 효과 그림이 있어 그림 재사용이 가장 많다.

## 목표 / 비목표 / 실패 조건

- 목표: 멀리서 하나씩 정확히 잡는 손맛. 덫으로 몰려오는 적을 끊는다. 다른 직업과 비슷한 난이도.
- 비목표: 새 상태 이상(둔화 등), 탄약, 여자 외형, 직업 일반화 리팩터링.
- 실패 조건: 마법사와 똑같이 느껴짐(범위로 다 쓸어버림), 또는 근접에 붙으면 아무것도 못 함.

## 방법 (검토한 것)

1. **마법사와 같은 경로(채택)**: `HeroClass`에 추가, 스킬은 `src/sim/ranger.ts`, 명령 분기(`world.ts` `command`)에서 직업별로 부른다. 스킬 칸·명령·재사용 필드·단계·특성은 공통 것을 쓴다.
2. 직업을 데이터(스킬 테이블)로 일반화: 직업 셋에는 과하다. 기각.
3. 기사 코드에 활 무기만 추가: 정체성이 생기지 않는다. 기각.

## 설계

### 기본

- id `ranger`, 이름 '궁수'(`Kind`의 `'archer'` = 스켈레톤 궁수와 구분).
- 체력 85, 레벨당 8 (기사 100/10, 마법사 70/6 사이). 최종 수치는 봇 테스트로.
- 평타 = 화살 투사체(마력탄과 같은 방식, `Shot.kind` 새 값 `'shaft'` 같은 이름으로 적 화살 `'arrow'`와 구분). 사거리 7.5m, 한 대상, 벽에 막힘.
- 패시브 **명사수**: 주인공에서 5m 넘게 떨어진 적에게 주는 평타·스킬 피해 +25%.
- 무기: 새총 → 단궁 → 장궁 → 대궁. 초당 피해는 같은 단계 검과 비슷(범위가 없으니 마법사보다 높게).
- 갑옷: 천옷 → 가죽 → 가죽+사슬 → 사슬 (감소율은 기사와 마법사 사이). 투구: 두건 → 가죽 두건 → 사슬 두건 → 판금 투구 이름만 궁수식. 신발은 공통 표에 이름만.
- 사슬 문: 화살(평타·관통 사격)로 끊는다.

### 스킬 (5단계, 3단계에서 특성 하나)

| 칸 | 스킬 | 특성 1 | 특성 2 | 5단계 |
|---|---|---|---|---|
| Q (`cleave`) | 관통 사격: 조준 방향 직선, 꿰뚫으며 맞은 적 모두 ×1.8 | 밀쳐내기(벽에 부딪히면 기절) | 세 갈래 | 두 발 연속 |
| W (`dash`) | 덫: 조준점(사거리 안)에 곰덫, 밟은 적 피해 + 1.5초 묶임(기절과 같은 `stunT`). 최대 2개, 넘으면 오래된 것 제거 | 폭발 덫(범위 피해) | 덫 3개 + 묶는 시간 증가 | 터질 때 주변 적도 묶음 |
| E (`shout`) | 화살비: 조준 원(낙뢰처럼 사거리로 당김)에 0.6초 뒤 범위 피해 | 불화살(불길 장판, 기존 `w.fires`) | 3초간 여러 번 | 범위 ×1.3 |
| R (`throw`) | 집중: 6초간 공격 속도 +40% | 멀티샷(평타 2발, 약간 벌어짐) | 치명(확률로 2배) | 집중 중 처치 시 재사용 대기 감소 |
| 스페이스 (`roll`) | 기사 구르기 그대로(조준 없으면 가까운 적 반대쪽) | | | |

단계마다 재사용 대기 감소·배율 증가는 마법사 `fireStat` 류와 같은 모양으로.

### 그림·소리

- `tools/sprites.py`: `RANGER_LAYERS`(무기 slingshot/shortbow/longbow/greatbow, 갑옷·두건 레이어), `CLASS_SHEETS`에 `'ranger'` + 공격 = `shoot`. 결과 `ranger_<레이어>_<단계>.png`, 초상, 장비·스킬 아이콘 줄.
- 화살 = 기존 `arrows` 시트. 덫 = Flare `bear_trap`/`bear_trap_trigger`. 화살비 = `arrows`를 떨어지는 방향으로 여러 개(또는 착탄 효과).
- 소리: 기존 활 소리(적 궁수)를 재사용.

### 연결

시작 화면 세 번째 직업, HUD 스킬·특성 문구·아이콘·초상(`hud.ts`의 직업별 Record), 장비 그림(`props.ts`), 저장(`save.ts`의 직업), 봇(`bot.ts`), `ranger.test.ts`, 플레이 테스트 밸런스(30판, 클리어·사망 수가 다른 직업과 비슷하게), README, CREDITS.
