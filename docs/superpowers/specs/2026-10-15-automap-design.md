# 5-A단계: 자동 지도(미니맵) 설계

- 날짜: 2026-10-15
- 목표: 어두운 48×48 층에서 지나온 길과 계단 위치를 기억할 수 있게, 탐험한 곳만 그려지는 디아블로식 자동 지도를 넣는다.
- 결정 사항(추천안 채택): 화면 오른쪽 위 상시 표시(작게), M 키·지도 버튼으로 숨기기/보이기. 화면과 같은 방향(45° 돌린 마름모, 세로 절반). 시야 판정은 횃불 반경 7m 원(벽 너머도 밝혀짐 — 단순화).

## 1. 탐험 기록 `src/render/automap.ts`

- 층마다 `explored: Uint8Array(w × h)`. 매 프레임 주인공 중심 반경 7m 안의 칸을 기록(`reveal`).
- 게임 규칙과 무관하므로 sim이 아니라 렌더 쪽 모듈. 새 층(setWorld)에서 초기화.

## 2. 그리기

- `<canvas id="automap">` 160×100 CSS px(기기 픽셀 비율 반영), 반투명 검정 배경.
- 탐험한 칸 중: 걸을 수 있는 칸 = 어두운 회색, 벽(걸을 수 있는 칸과 이웃한 막힌 칸) = 밝은 갈색 선 느낌의 칸, 계단 = 노란 칸, 화로 = 주황 점, 주인공 = 흰 점.
- 화면 방향 일치: 월드 (x, z) → 지도 (x − z, (x + z) / 2) × 칸 크기, 주인공이 지도 가운데.
- 매 프레임 다시 그린다(칸 수 ≤ 2304, 캔버스 2D로 충분).

## 3. 입력

- `M` 키(e.code `KeyM`)와 지도 버튼(오른쪽 위, 모바일)으로 표시 전환. 기본 표시.

## 4. 범위 밖

시야선(LOS) 판정, 전체 화면 지도, 몬스터 표시, 층 사이 지도 보존.

## 5. 완료 기준

1. `npm test`: `reveal`이 반경 안 칸만 기록(경계·맵 밖 안전), 지도 좌표 변환(주인공 = 가운데, +x는 오른쪽 아래).
2. `npm run build`.
3. 헤드리스: 시작 시 주변만 보이고, 이동하면 지도가 늘어나며, 계단을 본 뒤 지도에 표시, M으로 숨김, 새 층에서 초기화, 콘솔 오류 없음.
