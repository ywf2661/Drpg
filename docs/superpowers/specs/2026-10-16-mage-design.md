# 15단계: 스켈레톤 마법사 설계

- 날짜: 2026-10-16
- 목표: 근접(다가옴)·궁수(제자리 사격)와 다른 세 번째 행동 — 거리를 벌리며 범위 폭발 화염구를 쏘는 적. 쫓아가 잡거나 폭발 범위를 피해야 한다.
- 결정 사항(추천안 채택): 3~4층 몬스터의 10%(봇 테스트 후 보스층 제외), 가까이 오면 물러남(구석이면 그 자리에서 시전), 화염구는 느리지만 폭발 범위가 있음.

## 1. 마법사

| 항목 | 값 |
|---|---|
| 이름 / 글자 | 스켈레톤 마법사 / `g` (`kind: 'mage'`) |
| 체력 | 22 |
| 화염구 피해 | 5–8 (× 층 배율 절반, 갑옷 감소; 7–11은 봇 테스트에서 과함) |
| 시전 간격 | 2.4초 (40% 시점에 발사) |
| 이동 속도 | 2.0m/s |
| 사거리 | 7m, 시야 필요 |
| 물러나기 | 주인공이 3m 안이고 시전 중이 아니면, 주인공 반대쪽 3칸 지점으로 경로를 찾아 이동(0.5초마다 다시 계산). 갈 곳이 없으면 시전 |
| 경험치 / 물약 / 장비 | 20 / 25% / 10% |

## 2. 화염구

- `Shot`에 `kind: 'arrow' | 'fire'` 추가. 화염구: 속도 6m/s, 비행 9m, 주인공 0.5m 이내·벽·비행 끝에서 **폭발**.
- 폭발: 중심 1.2m 안의 살아 있는 주인공에게 피해(직격과 폭발이 겹쳐도 한 번). `World.blasts: { id, x, z, age }[]` 기록(렌더·소리용, 0.6초 뒤 sim이 지움).

## 3. 생성기

- 3~4층에 `round(몬스터 수 × 0.1)`마리를 마법사로(5층은 보스에 집중하도록 제외)(궁수·전사 수 그대로, 나머지 졸개에서 뺌).

## 4. 그림·소리

- FLARE `enemies/skeleton_mage`(공격 = `cast`), 화염구 `powers/fireball`(8방향 4프레임), 폭발 `powers/blast`(6프레임, 방향 0).
- 소리: 시전 `fireball.ogg`(화염구가 생김), 폭발 `burn.ogg`.

## 5. 완료 기준

1. `npm test`: 멀리서 시전·폭발 피해, 벽에서 폭발(벽 옆 주인공도 피해), 옆으로 피하면 피해 없음, 가까이 가면 물러남, 구석이면 시전, 생성기 수(1·2·5층 0, 3~4층 10%), 봇 1~5층, 시트 계약, 소리 이벤트.
2. `npm run build`.
3. 헤드리스: 화염구·폭발 그림, 콘솔 오류 없음.
