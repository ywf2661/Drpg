# 13단계: 보물 상자 설계

- 날짜: 2026-10-15
- 목표: 장식뿐인 상자를 열 수 있게 해 탐험 보상을 만든다.
- 결정 사항(추천안 채택): 클릭하면 다가가서 연다, 한 번만 열린다, 내용물은 바닥에 떨어져 기존 줍기 규칙을 따른다.

## 1. 생성기

- 맵 글자 `c` = 상자(막힘). 방마다 35% 확률로 1개, 막는 소품과 같은 규칙(뒤쪽 가장자리, 복도 입구 아님, 계단·보스·주인공 근처 아님, 연결성 유지).

## 2. 규칙

- `World.chests: { id, x, z, open }[]`(칸 좌표). 명령 `{ type: 'open'; chestId }`.
- 열기: 상자에 이웃한 걸을 수 있는 칸으로 걸어가 상자 중심과 1.3m 이내가 되면 연다. 다른 명령이 오면 취소.
- 내용물: 60% 물약, 40% 장비(무기·갑옷 반반, 단계 1..maxTier). 상자와 주인공 사이(상자 중심에서 주인공 쪽 0.7m)에 떨어짐.
- 이미 열린 상자·사망 상태에서는 무시.

## 3. 그림·소리·입력

- 시트 `props`에 `chest_open`, `chest2_open`(FLARE 타일 160, 161) 추가. 닫힌 상자는 `chest`/`chest2`(칸 해시로 고름), 열리면 같은 번호의 열린 그림.
- 클릭 판정: 몬스터 다음으로 상자(칸 중심 세로 선분 0~0.8m, 반경 0.5m). 커서는 평소 모양.
- 소리: FLARE `wood_open.ogg`(상자가 열린 프레임).

## 4. 완료 기준

1. `npm test`: 생성기 상자 수·위치 규칙·연결성, 걸어가서 열기, 한 번만, 내용물 확률·위치, 다른 명령으로 취소, 사망 시 불가, 소리 이벤트, 시트 계약.
2. `npm run build`.
3. 헤드리스: 상자 클릭 → 걸어가 열림, 열린 그림·아이템·소리 이벤트, 콘솔 오류 없음.
