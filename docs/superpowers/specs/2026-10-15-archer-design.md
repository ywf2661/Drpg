# 7단계: 원거리 몬스터(스켈레톤 궁수) 설계

- 날짜: 2026-10-15
- 목표: 근접 몬스터뿐인 전투에 거리 조절·회피 요소를 더한다. 화살은 실제로 날아가므로 옆으로 움직여 피할 수 있다.
- 결정 사항(추천안 채택): 2층부터 등장(몬스터의 15%), 사거리 6m·시야선 필요, 화살 속도 9m/s, 벽에 막힘, 궁수는 거리를 벌리지 않음(단순 AI).

## 1. 궁수

| 항목 | 값 |
|---|---|
| 이름 / 글자 | 스켈레톤 궁수 / `a` (`kind: 'archer'`) |
| 체력 | 25 |
| 화살 피해 | 4–7 (× 층 배율, 갑옷 감소) |
| 쏘는 간격 | 1.8초 (40% 시점에 화살 발사) |
| 이동 속도 | 2.2m/s |
| 사거리 | 6m, 둘 사이 직선이 벽을 지나지 않아야 함(기존 canHit 시야 검사) |
| 경험치 / 물약 / 장비 | 15 / 25% / 8% |

## 2. 화살 `World.shots`

- `{ id, x, z, dx, dz, dmg, left }`: 발사 시점 대상 위치를 향한 단위 방향, 데미지는 발사 때 굴림(재현성), `left` = 남은 비행 거리(8m).
- 매 틱 `9m/s × DT`씩 이동. 막힌 칸에 들어가면 사라짐. 살아 있는 주인공 중심 0.4m 이내면 피해(갑옷 적용) 후 사라짐. 남은 거리가 0이면 사라짐.
- 피해 처리는 근접과 같은 함수(`hurt`)를 공유: 갑옷, 사망, 드롭, 경험치.

## 3. 생성기

- 몬스터 수 그대로, 2층부터 `round(수 × 0.15)`마리를 궁수로(전사 수는 그대로, 나머지 졸개).

## 4. 그림·소리

- FLARE `enemies/skeleton_archer`: 공격 동작은 `shoot`. 화살 `powers/arrows`(8방향 3프레임, 비행 높이 포함) 시트 `arrow`.
- 소리: 발사 `shoot.ogg`, 벽에 맞음 `arrow_wall.ogg`(선택: 생략 — 발사음만).

## 5. 완료 기준

1. `npm test`: 궁수가 멀리서 쏘고 화살이 날아가 맞힘, 벽에 막힘, 옆으로 피하면 빗나감, 시야가 막히면 쏘지 않고 다가감, 생성기 궁수 수(1층 0, 2층부터 15%), 시트 계약.
2. `npm run build`.
3. 헤드리스: 화살 그림이 날아가고 발사음 이벤트, 콘솔 오류 없음.
