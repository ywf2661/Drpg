# 기사 5번째 탭 「벼림」 설계

- 날짜: 2026-11-17
- 계기: 사용자 "무기강화류 스킬트리 — 스킬을 쓰면 무기가 은은하게 빛나면서 추가 피해를 입힌다". 대화에서 5번째 탭으로 정했다.
- 목표: 칼에 힘을 입혀 두고 휘두를 때마다 쏟아 내는 손맛. 강화는 **시간이 아니라 타수(충전)** 로 세서 "켜 두고 잊는 버프"가 되지 않게 하고, "어디에 충전을 쏟을지·언제 갈아입을지"를 선택으로 만든다.
- 상태: 설계(사용자 승인 — "그대로 개발해도 되겠다")
- 선행 작업: 4번째 탭 「발도」(`specs/2026-11-17-iaido-tab-design.md`). 발도가 여는 탭 개수 구조(`TREES: Record<HeroClass, Tab[]>`) 위에 얹는다. **발도 구현이 끝나 커밋된 뒤에 시작한다**(같은 파일 `rules.ts`·`core.ts`·`hud.ts`·`save.ts`를 고친다).

## 하지 않는 것

- 기존 검술·돌격·투척·발도 탭의 수치와 동작(아래 "충전을 쓰는 타격" 목록에 이름이 오르는 것 말고는 그대로).
- 봇의 기본 빌드(`BASIC`).
- 새 주인공 그림. 무기 층 물들이기와 효과만으로 빛낸다.
- 적에게 붙는 지속 피해(화상)·이동 감속. 지금 sim에 없는 상태라 이번에는 만들지 않는다(불 벼림은 추가 피해만, 서리 벼림은 빙결만).

## 실패로 보는 것

- 칼이 빛나는지, 무슨 색인지, 충전이 얼마 남았는지 화면에서 모르는 것(낮 바깥 지역 포함 — 횃불 빛은 낮에 꺼진다).
- 강화를 켜고 끌 때 주인공 그림이 깜빡이거나 멈칫하는 것.
- 불 벼림 1점이 어느 빌드에서나 "무조건 찍는" 정답이 되는 것(보조로 좋되 주 트리 스킬을 밀어내면 안 된다).
- 덧벼림 폭발이 회오리와 겹쳐 생각 없이 이기는 것.

## 고른 방식(대화에서)

| 결정 | 고른 것 | 버린 것과 이유 |
|---|---|---|
| 탭 자리 | **5번째 탭** | 돌격 교체(돌진·도약의 맛이 사라짐), 다른 직업으로(사용자: 기사) |
| 강화 단위 | **타수(충전)** | 시간(켜 두고 잊는 버프가 되어 단조롭다) |
| 강화 개수 | **칼에 하나만**, 새로 쓰면 덮어쓴다 | 겹쳐 쌓기(선택이 사라진다) |
| 투척 탭 | **지금 그대로** | 「박고, 부른다」 개편(사용자: 투척은 둔다) |

## 1. 충전 (sim)

- 주인공 상태에 `edge: { kind: 'flame' | 'frost' | 'both' | null; left: number; t: number }`(이름은 짓는 사람 몫). `left` = 남은 충전, `t` = 해방의 남은 시간(해방일 때만).
- **한 번 휘두르면 충전 1**. 한 번의 휘두름이 여러 적을 맞혀도 1만 줄고, 맞은 적 **모두**에게 강화 효과가 붙는다. 아무도 못 맞힌 휘두름은 충전을 쓰지 않는다.
- 충전이 0이 되면 강화가 꺼진다(`kind = null`).
- 층을 옮기거나 저장·불러오기를 하면 강화는 꺼진다(저장하지 않는다 — 기력과 같은 이유).

**충전을 쓰는 타격(칼로 베는 근접만)**: 평타, 가르기, 회오리(0.25초 틱마다 한 번의 휘두름), 처형, 돌진 베기, 대지 강타 착지, 그어두기, 일섬(꿰뚫을 때마다).
**쓰지 않는 것**: 도끼 셋, 불길, 시체 폭발, 검흔이 터지는 피해(저절로·납도), 덧벼림 폭발 자신.

구현 힌트: 위 타격들이 맞힌 적 목록을 한 함수(`temper(w, hit: Entity[])` 같은)에 넘겨 충전 차감·효과를 한 곳에서 처리한다.

## 2. 스킬 (`TREES.knight[4] = { name: '벼림', skills: [...] }`)

스킬 id는 예시(`flameEdge`, `frostEdge`, `reforge`, `unleash`), 짓는 사람 몫.

| 자리 | 스킬 | 동작 | 1단계 수치(시작값) | 단계마다 | 5단계 완성 |
|---|---|---|---|---|---|
| 1 (Lv1) | **불 벼림** (주황) | 칼에 불을 입힌다. 충전 6. 휘두름에 맞은 적마다 **평타 굴림 × 0.4** 추가 화염 피해 | 대기 4초, 기력 16 | 배율 +0.1 | 충전 다 쓰는 마지막 휘두름이 맞힌 적 자리에서 작은 화염 폭발(반경 1.5m, 평타 굴림 × 0.6) |
| 2 (Lv4) | **서리 벼림** (파랑) | 칼에 서리를 입힌다. 충전 6. 같은 적을 서리 칼로 **세 번** 맞히면 1초 빙결(기존 `stun`, 얼음 효과 그림) — 언 적은 기존 연계대로 약점 ×1.5 | 대기 6초, 기력 24 | 빙결 +0.15초 | 두 번 맞혀도 언다 |
| 패시브 (Lv8) | **덧벼림** | 충전이 남은 채 다른 벼림(또는 해방)을 쓰면 남은 충전이 한꺼번에 터진다. 주인공 주위 2.5m 적 모두에게 **남은 충전 × 평타 굴림 × 0.3**. 불이면 화염 폭발 그림, 서리면 피해 + 0.8초 빙결 + 얼음 폭발 그림 | — | 벼림 충전 +1, 폭발 배율 +0.05 | — |
| 궁극 (Lv12) | **검기 해방** (흰빛) | 6초 동안 불과 서리가 함께 깃든다(충전 없이 무제한 — 둘 다 적용). 그동안 휘두를 때마다 칼날의 빛이 앞으로 날아가 **앞쪽 3m·폭 0.8m** 안의 적 모두에게 평타 굴림 × 0.5(이 참격도 강화 효과를 받는다) | 대기 15초, 기력 36 | 지속 +0.5초, 대기 −0.5초 | — |

- 서리 벼림의 "세 번"은 적마다 센다(`Entity`에 작은 수 하나). 강화가 꺼지거나 바뀌면 센 수는 지운다.
- 해방 중에는 불·서리 벼림을 쓸 수 없다(칸이 어둡게, 비용·대기 없음). 해방이 끝나면 칼은 빈다.
- 추가 화염 피해·참격은 `skillHit`을 거친다(받아치기·약점·등 뒤가 그대로 붙는다). 평타에 붙은 추가 피해도 마찬가지 — 평타 자체에는 연계가 없지만 불꽃은 스킬 피해로 본다.
- 시너지(`syn`)·`+N` 옵션·전설은 기존 규칙대로 탭 4를 포함한다.

| 수치 상수(`rules.ts`, 봇·플레이로 조정) | |
|---|---|
| `TEMPER.charges` | 6 |
| 불 배율 | 0.4 (+0.1/단계) |
| 서리 빙결 타수 · 시간 | 3타 · 1초 (+0.15/단계) |
| 덧벼림 반경 · 배율 | 2.5m · 0.3 (+0.05/단계) |
| 해방 시간 · 참격 길이 · 폭 · 배율 | 6초 · 3m · 0.8m · 0.5 |

## 3. 탭 개수

- `TREES.knight`가 5개. 탭 `+1` 옵션 굴림은 발도가 바꾼 대로 `TREES[cls].length`를 쓰므로 그대로 된다.
- 저장 검사(`save.ts`): 탭 옵션 `tab` 허용 범위를 0~4로.
- `legend.test.ts` 등 탭 수를 셈하는 테스트를 직업 탭 수에 맞춘다.
- **스킬 창 탭 머리 다섯 개가 360px 폭에서 한 줄에 들어가는지** 확인(검술·돌격·투척·발도·벼림 — 모두 두 글자).

## 4. 화면

**칼 빛 (가장 중요)**
- 무기 층(`HERO_LAYERS`의 `main`)을 강화 색으로 물들인다. 전설 원색 외형의 `tinted(url, color)`가 이미 url+색마다 한 번 만들어 캐시하므로 같은 길을 쓴다.
- 색마다 처음 켤 때 한 번 비동기로 합친다. **준비되기 전에는 지금 그림을 그대로 두고**(깜빡임 금지), 준비되면 텍스처만 바꾼다. 꺼질 때는 원래 텍스처로 되돌린다.
- 색: 불 주황, 서리 하늘색, 해방 흰색(값은 짓는 사람 몫, 전설 원색과 헷갈리지 않게 밝고 옅게).
- 횃불 빛(`render.ts`의 `torch`)은 밤에만 켜지므로 보조로만 쓴다: 강화 중에는 색을 강화 색 쪽으로 30% 섞는다.
- 낮에도 보이도록 주인공 손 높이에 작은 가산 혼합 빛 점(또는 불티 입자)을 강화 색으로 둔다.

**충전 표시**
- 휘두를 때마다 칼끝 높이에서 불티(불)·얼음 조각(서리)이 떨어진다.
- 남은 충전이 1이면 칼 빛이 깜빡인다.
- 불·서리 벼림을 끼운 칸에 남은 충전 수를 작게 띄운다.

**타격**
- 추가 화염 피해는 데미지 숫자를 주황으로(지원되면), 빙결은 기존 얼음 폭발 그림.
- 덧벼림 폭발: 기존 `blasts`의 화염·얼음 그림을 반경에 맞춰.
- 해방 참격: 가르기 효과 그림을 가늘고 하얗게 앞으로 3m 늘인 칼선(0.15초).

**소리**: 새 소리 없이 기존 것(불·얼음·가르기)을 붙인다.

## 5. 다른 탭과의 보조 궁합(의도)

- **불 벼림 1점 = 범용 보조**. 회오리 빌드는 2초 만에 6타를 쏟는 폭딜 스위치가 된다(회오리 틱이 한 번의 휘두름이므로).
- **발도와의 연결(선택, 이번 범위에 넣을지 짓는 사람과 상의)**: 납도로 칼을 넣는 순간 남은 충전을 모두 쓰고, 터지는 검흔마다 강화 효과(불: 추가 피해, 서리: 빙결)를 한 번 준다. 넣지 않아도 탭은 완결된다.

## 6. 봇·테스트

- `src/sim/temper.test.ts`:
  - 불 벼림: 충전 6, 휘두름마다 1 감소, 여러 적을 맞혀도 1, 못 맞히면 감소 없음, 추가 피해 = 평타 굴림 × 배율, 0이면 꺼짐, 5단계 마지막 폭발.
  - 서리 벼림: 같은 적 3타에 빙결(5단계 2타), 강화가 바뀌면 센 수 초기화.
  - 덧벼림: 남은 충전 × 배율 폭발, 배우기 전에는 그냥 덮어씀, 충전 +1/단계.
  - 해방: 6초 무제한, 불+서리 함께, 앞쪽 3m 참격, 해방 중 벼림 사용 불가, 끝나면 빈 칼.
  - 충전을 쓰는 타격 목록(도끼·불길·시체 폭발·검흔 폭발은 안 씀).
  - 층 이동·불러오기 후 강화 꺼짐.
- 탭 구조: 기사 탭 5, 저장 검사(탭 4 통과, 5 거부).
- 렌더: 색 결정·깜빡임 판단을 순수 함수로 빼서 테스트.
- 봇 `BASIC`은 그대로. 불 벼림 1점을 회오리 빌드에 얹은 봇 10판을 돌려 클리어·사망 수를 이 문서 "구현"에 적는다(얹지 않은 쪽보다 압도적이면 배율을 낮춘다).

## 짓는 사람 몫

- 스킬 id, 상태 필드 이름, 빛 점·불티의 크기와 색값.
- 칼 빛을 물들인 시트로 할지, 무기 층 위에 겹치는 가산 혼합 층으로 할지(위 "깜빡임 금지"만 지키면 된다).
- 해방 참격을 즉시 판정으로 할지 짧은 투사체로 할지(위 수치를 지키는 쪽으로).

## 구현

- 계획: `docs/superpowers/plans/2026-11-17-temper-tab.md`. 규칙은 `src/sim/temper.ts`, 화면은 `src/render/edge.ts`(순수 판단)·`src/render/temper.ts`(빛 점·불티·참격).
- 칼 상태는 `World.edge`, 서리 타수는 `Entity.frost`. 칼로 벤 여덟 타격이 맞힌 적 목록을 `temper()`에 넘긴다.
- 해방 참격은 즉시 판정(앞 3m, 칼선에서 옆으로 0.4m, 시선이 트인 적). 가르기·그어두기·회오리 틱·대지 강타 착지는 빈 휘두름에도 참격이 나간다.
- 칼 빛: 무기 층을 강화 색으로 물들이고(`looksOf`, 다 그린 뒤에야 바꿔 깜빡이지 않는다), 손 쪽에 가산 혼합 빛 점(충전 1이면 깜빡), 횃불 색 30% 섞기.
- 발도와의 연결(납도로 충전 쓰기)과 주황 데미지 숫자는 넣지 않았다.
- 봇 10판(시드 1~10, 미궁): 회오리 빌드(Q 가르기·W 회오리·E 함성·R 도끼) 클리어 9, 사망 21 / 같은 빌드의 R을 불 벼림 1점으로 바꾼 벼림 빌드 클리어 8, 사망 31. 깬 판의 평균 시간은 벼림 쪽이 빠르다(448초 → 400초). 압도적이지 않아 불 배율 0.4를 그대로 둔다.
