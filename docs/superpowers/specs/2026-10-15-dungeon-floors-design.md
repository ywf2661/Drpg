# 2-A단계: 던전 생성과 층 이동 설계

- 날짜: 2026-10-15
- 목표: 고정 맵 하나를 무작위로 생성되는 5개 층으로 바꾸고, 계단으로 내려가며 점점 어려워지는 반복 플레이 구조를 만든다.
- 결정 사항: 5층 구조(보스는 4단계, 그 전까지는 5층 전멸 = 클리어), 사망 시 그 층을 새로 생성해 재시작, 방 + 복도 구조, 무작위 방 배치 + L자 복도, 계단은 언제든 이용, 내려가면 체력 완전 회복.
- 후속: 2-B단계에서 FLARE 바닥 질감·화로(조명)·계단·소품 그림. 2-A의 계단은 임시 표시.

## 1. 맵 생성 `src/sim/dungeon.ts`

`generateFloor(seed: number, floor: number): string[]` — 순수 함수, 시드로 재현. 결과는 기존 글자 맵 형식(`#` 벽, `.` 바닥, `H` 주인공, `m` 졸개, `w` 전사) + `>` 계단.

1. 48×48을 벽으로 채운다. 난수는 함수 안의 mulberry32(시드)만 쓴다.
2. 방: 목표 개수 6~9개, 한 변 5~10칸. 최대 300번 시도하며, 기존 방과 2칸 이상 떨어진 경우에만 놓는다. 테두리 1칸은 항상 벽.
3. 복도: 방 i(1부터)를 방 i−1과 L자(가로 먼저 또는 세로 먼저, 무작위)로 잇는다. 폭 2칸. 순환로를 위해 무작위 방 쌍 2개를 더 잇는다.
4. 주인공: 첫 방 중심.
5. 계단(1~4층): 주인공 칸에서 걸어서(4방향 BFS) 가장 먼 방의 중심. 5층은 계단 없음.
6. 몬스터: 수 `8 + 3 × (층 − 1)`, 전사 비율 `0.2 + 0.075 × (층 − 1)`(반올림, 5층 50%). 첫 방을 뺀 방들에 돌아가며 2~4마리 무리로, 방 안의 빈 `.` 칸에 무작위 배치.

## 2. sim 변경 `src/sim/world.ts`

- `createWorld(seed, map, power = 1)`: 기본 맵 인자 제거(고정 `MAP`은 테스트 픽스처로 이동). `>`는 바닥 칸으로 읽고 `world.stairs = [x, z] | null`에 기록.
- `Entity`에 `maxHp`, `power` 추가. 주인공 `power = 1`, 몬스터 `power = 인자`. 몬스터 체력 = `round(STATS.hp × power)`, 데미지 = `round(기본 데미지 × 공격자 power)`.
- `outcome(w)`: `'dead'`(주인공 사망) → `'descend'`(계단 칸 중심 0.5m 이내) → `'clear'`(계단이 없는 층에서 몬스터 전멸) → `null` 순서로 판정.
- 층 배율 `power = 1 + 0.2 × (층 − 1)`.

## 3. 길찾기 성능 `src/sim/path.ts`

맵이 32×32 → 48×48로 커지고 몬스터가 최대 20마리라 open 목록 선형 탐색을 이진 힙으로 교체한다(기존 ponytail 주석의 업그레이드 경로). 결과 경로는 동일한 비용의 최단 경로(기존 테스트 유지).

## 4. 진행 흐름 `src/main.ts`

- 상태: 현재 층 `floor`(1~5). 층을 만들 때마다 새 시드(`Math.random`, sim 밖).
- `'descend'` → 다음 층 생성(체력 완전 회복) + 화면 중앙에 "지하 N층" 문구 2초 표시.
- `'dead'` → "사망했습니다" + [다시 시작 (R)] → 같은 층을 새 시드로 생성.
- `'clear'`(5층) → "클리어!" + [다시 시작 (R)] → 1층부터.
- 화면 왼쪽 위에 "지하 N층" 상시 표시. 체력바는 `maxHp` 기준.

## 5. 렌더 `src/render/render.ts`

- `setWorld(world)`가 바닥·벽도 새로 만든다(이전 층 메시와 지오메트리·재질 해제).
- 계단(임시): 계단 칸에 검은 사각 구멍(바닥 위 0.02m 평면).

## 6. 범위 밖

FLARE 바닥 질감·소품·화로 조명·계단 그림(2-B), 보스(4단계), 아이템·물약(3단계), 미니맵, 층 사이 상태 유지(장비·레벨).

## 7. 완료 기준

1. `npm test` 통과: 기존 테스트 + 생성기 테스트(아래) + 층 배율·계단 판정 테스트.
   - 시드 1~50 × 층 1~5: 48×48, 테두리 벽, `H` 1개, 계단 수(1~4층 1개, 5층 0개), 몬스터 수·전사 수, 모든 비벽 칸이 주인공에서 도달 가능, 계단이 주인공에서 걸어서 15칸 이상 떨어짐, 같은 시드 = 같은 맵.
2. `npm run build` 성공.
3. 헤드리스 Chrome: 1층 시작 → 계단까지 이동 → "지하 2층" 표시와 새 맵, 체력 100%. 사망 시 같은 층 새 맵으로 재시작. 콘솔 오류 없음.
