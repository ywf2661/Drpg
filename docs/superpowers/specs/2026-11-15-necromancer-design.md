# 강령술사(네크로맨서) 설계

## 목표
- 네 번째 직업. 해골 병사를 불러 대신 싸우게 하고, 저주·생명 흡수로 버티는 소환사.
- 스킬 칸·명령·재사용 필드·단계·특성은 기사·마법사·궁수와 같은 것을 쓴다(궁수 추가 방식 그대로).
- 봇 30판: 스킬을 쓰면 대부분 깨고, 스킬 없이는 못 깬다.

## 비목표
- 해골 병사는 승패·경험치·드롭에 끼지 않는다(`entities` 밖). 보스·해골 왕은 해골에게 맞아도 주인공을 놓지 않는다.
- 새 그림을 그리지 않는다: 주인공은 FLARE 레이어를 다시 칠해 조합(`tools/sprites.py`의 `NECRO_LAYERS`), 해골 병사는 졸개 그림을 초록빛으로.

## 설계
| 칸 | 이름 | 하는 일 | 특성 1 / 2 | 5단계 |
|---|---|---|---|---|
| 평타 | 뼈 화살 | 마법사 마력탄과 같은 원거리 탄 | — | — |
| Q | 해골 병사 | 주변에 해골 2기 소환(최대 4, 14초). 해골은 가까운 적을 쫓아 근접 공격(강령술사 굴림 × 배율) | 군단(+2기, 약하게) / 정예 해골(강하고 오래) | +1기 |
| W | 생명 흡수 | 반경 3m 적 모두 피해, 준 피해의 40% 회복 | 넓은 흡수(반경 ×1.5) / 갈증(회복 2배) | 적을 맞히면 해골 1기 |
| E | 저주 | 조준 지점 반경 2.2m에 6초 저주: 안의 적이 받는 모든 피해 +35%. 닫힌 사슬 문도 녹인다 | 넓은 저주(반경 ×1.6) / 역병(0.5초마다 피해) | 저주 안의 시체가 해골로 일어난다(시체마다 한 번) |
| R | 뼈 갑옷 | 6초 동안 최대 체력 25% 흡수(마나 방패와 같은 장치) | 시체 일으키기(쓰면 해골 2기) / 가시 뼈(흡수한 피해 50% 반사) | 깨지면 주변 폭발 |
| 스페이스 | 구르기 | 기사와 같다 | | |

- 체력 75(+7/레벨), 방어는 마법사와 같다. 무기 수치는 마법사 지팡이와 같다(해골이 따로 친다).
- sim: `World.allies`(해골, `entities` 밖), `World.curses`, `World.raised`. 저주 배율은 core `hurt`가 적용.
- 해골의 피해는 `hurt(…, hero)`로 → 경험치·드롭·흡혈은 주인공 것.
- 몬스터는 주인공·해골 중 가까운 쪽을 노리고, 해골에게 맞으면 그 해골로 돌아선다. 근접·화살·화염구·내려찍기·돌진 모두 해골도 맞는다. 해골 체력 = 강령술사 최대 체력의 30%, 0이 되면 무너진다.
- 외형: 보라 치마 위에 단계별로 창백한 맨몸 → 검은 가죽 → 사슬 → 판금, 머리는 민머리 → 검은 두건 → 보라 두건 → 투구.
