# Drpg

디아블로 1풍의 2.5D 웹 액션 RPG. 횃불 하나에 의지해 무작위로 만들어지는 지하 5층을 내려가 미노타우르스를 쓰러뜨리면 클리어.

**플레이:** https://ywf2661.github.io/Drpg/ (PC·모바일 브라우저)

## 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | 땅을 클릭(누르고 있으면 계속 따라감) | 터치·드래그 |
| 공격 | 몬스터 클릭(죽을 때까지 반복) | 몬스터 터치 |
| 가르기(전방 범위 150%, 4초) | `Q` / 우클릭(커서 방향) | 스킬 버튼 |
| 돌진 베기(5m, 길 위 적 100%, 6초) | `W`(커서 방향) | 돌진 버튼 |
| 전투의 함성(4m 기절 2초, 받는 피해 −30% 6초, 15초) | `E` | 함성 버튼 |
| 도끼 던지기(처음 닿는 적 120%, 2.5초) | `R`(커서 방향) | 도끼 버튼 |
| 구르기(3m, 구르는 동안 무적, 1초) | `Space`(커서 방향) | 구르기 버튼(적 반대쪽) |
| 물약 마시기(4초에 걸쳐 최대 체력 50%) | `1` | 물약 버튼 |
| 보관함(직접 장착·버리기, 자동 장착 끄기) | `I` | 가방 버튼·장비 칸 |
| 스킬 단계 올리기(레벨업마다 포인트 1, 최대 5단계) | `Shift`+`Q`·`W`·`E`·`R` | 스킬 버튼의 [+] |
| 보물 상자 열기 | 상자 클릭 | 상자 터치 |
| 계단 내려가기 | 계단 그림 클릭 | 계단 터치 |
| 지도 보이기/숨기기 | `M` | 지도 버튼 |
| 다시 시작(사망·클리어 후) | `R` | 다시 시작 버튼 |

## 게임 요소

- **던전:** 층마다 새로 만드는 48×48 방+복도(1~3층 벽돌 던전, 4~5층 동굴), 화로 불빛, 소품, 보물 상자, 자동 지도. 층이 깊을수록 몬스터가 강하고 많다.
- **몬스터:** 스켈레톤 졸개·전사, 2층부터 궁수(화살은 피할 수 있음), 3~4층 마법사(물러나며 범위 폭발 화염구), 2~4층 금빛 정예 전사(최고 단계 장비 확정), 3층 중간 보스 해골 왕(졸개 소환), 5층 보스 미노타우르스(붉게 달아오르면 돌진 — 옆으로 피할 것).
- **성장:** 경험치·레벨(체력 +10, 공격력 +5%/레벨), 스킬 4개(가르기·돌진 베기·전투의 함성·도끼 던지기, 레벨업 포인트로 각각 5단계까지 성장, 5단계에는 완성 효과: 한 바퀴 가르기·연쇄 돌진·함성 회복·관통 도끼. 연계: 예고 중인 적에게 스킬 2배, 기절한 적 1.5배, 돌진이 맞으면 가르기 준비), 무기 4단계(단검~그레이트소드)·갑옷 4단계(천옷~판금, 피해 감소)·투구 4단계(천 두건~판금 투구, 최대 체력)·신발 4단계(샌들~판금 장화, 이동 속도) — 장비에는 마법 옵션이 붙는다(일반·마법·희귀; 무기: 데미지·공격 속도·흡혈·치명타, 갑옷: 체력·피해 감소·재생·가시, 투구: 체력·피해 감소·가시, 신발: 체력·재생·이동 속도). 장비를 밟으면 보관함(8칸)으로 들어오고, 옵션까지 따져 더 좋은 장비(▲)는 바로 장착되며 외형도 바뀐다. 자동 장착을 끄면 빌드를 직접 고를 수 있다.
- **직업:** 시작 화면에서 고른다. 기사(근접, 위의 스킬), 마법사(원거리 마력탄, 화염구·서리 고리·낙뢰·마나 방패·순간이동, 스킬마다 5단계 완성 효과와 특성 둘). 마법사는 체력·방어가 낮고 지팡이·로브를 입는다. 궁수(가장 먼 화살, 5m 밖의 적에게 피해 +25%, 관통 사격·덫·화살비·집중·구르기)는 활과 가죽옷을 쓴다.
- **조준:** 날아가는 스킬(도끼·돌진·화염구)은 직선, 지점에 떨어지는 스킬(낙뢰)은 원 궤적을 보고 클릭해서 쓴다. 설정의 '스마트 키'를 켜면 누르는 순간 커서 쪽으로.
- **금화·상점:** 몬스터·상자가 금화를 떨어뜨리고, 계단을 내려갈 때마다 상인에게서 물약을 사거나 무기·갑옷·투구·신발을 한 단계 강화하고, 보관함 장비를 팔 수 있다.
- **진행:** 층에 들어갈 때 자동 저장(이어하기), 사망하면 그 층을 새로 만들어 들어올 때 상태로 재도전, 클리어하면 결과(시간·처치·사망) 표시. 클리어 후 **다음 회차**로 레벨·장비를 유지한 채 더 강한 던전에 다시 도전할 수 있다.

## 개발

Node.js 20.19+ (Vite 8 요구), Python 3 + Pillow(그림 변환할 때만).

```bash
npm install
npm run dev      # 개발 서버
npm test         # Vitest — 게임 규칙, 생성기, 시트 계약, 봇 1~5층 플레이(밸런스 회귀)
npm run build    # 타입 검사 + 배포 빌드(dist/)
python tools/sprites.py   # FLARE 원본을 받아 시트·질감·효과음 재생성(결과는 커밋되어 있음)
```

`main`에 push하면 GitHub Actions가 테스트·빌드 후 GitHub Pages로 배포한다.

## 구조

| 경로 | 역할 |
|---|---|
| `src/sim/` | 게임 규칙(three.js 없음, 시드 PRNG로 재현). `world.ts` 진입점(맵 읽기·한 틱·명령·기본 AI), `rules.ts` 수치·타입, `core.ts` 공용 전투(피해·드롭·레벨·걷기), `abilities.ts` 스킬·보스 패턴·투사체, `dungeon.ts` 층 생성, `path.ts` A*, `bot.ts` 테스트용 봇 |
| `src/render/` | three.js 렌더(정사영 30° 카메라, 도트 빌보드 스프라이트, 바닥·벽, 소품·화로 빛, 앞쪽 벽 낮추기, 자동 지도, 이름표) |
| `src/audio/` | 상태 변화 → 효과음 이벤트(순수 함수)와 Web Audio 재생 |
| `src/main.ts` | 게임 루프(60Hz 고정 틱), 층 진행·상점·저장·회차 |
| `src/hud.ts` | 화면 위 HTML(체력·경험치·스킬·물약·장비·금화, 보스 체력바, 배너, 상점 화면) |
| `src/shop.ts`, `src/save.ts` | 상점 가격·구매(순수 함수), 저장·이어하기(검증 포함) |
| `src/input.ts` | 마우스·터치 → sim 명령 |
| `tools/sprites.py` | FLARE 그림·소리 변환 |
| `docs/superpowers/` | 단계별 설계서(specs)와 구현 계획(plans) |
